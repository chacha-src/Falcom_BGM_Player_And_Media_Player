Importing playlists from other software

Playlists you built in another program do not need rebuilding. Raira reads m3u, m3u8, pls and xspf as they are.

Importing

  1. Right-click the playlist and choose the playlist import command.
  2. Pick the file you want to bring in.
  3. Check the import options and run it.
  4. If any rows come in with a missing mark, fix the paths with the missing-file review in Working with playlists.

The import options

Character encoding
UTF-8 files are read correctly. m3u8 is UTF-8 by definition, so non-ASCII file names survive intact.
Relative paths
Paths relative to the playlist's own location are resolved, which often means a collection moved wholesale to another PC still reads.
Skip missing
Rows whose file does not actually exist are left out.
Skip duplicates
Tracks already in the list are not added twice.

Worth doing afterwards

  • Blank titles or artists can be tidied in bulk with Editing tags.
  • Registering the collection in Smart playlists and the library tree lets you recall tracks by rule later on.
  • With a large import, Looking back at play history helps you spot what you actually listen to so you can split it into a smaller list.
Tip

If what you really want is a list that follows a folder rather than a one-off import, the folder sync lists in Working with playlists are a better fit — drop music into the folder and the list grows.

Please note

What comes across is the playlist contents, that is, the track order. Ratings or custom tags added by other software are not carried over.
