Update checks

Raira checks whether a newer version is available when it starts, and again periodically while you use it. You are told when there is something new.

When it checks

  • At startup.
  • Periodically while the program stays open.

When a new version exists

You get a notification. Follow it to install the new version — your settings and playlists carry over.

The ZIP used by automatic update is the same oggYSEDbgm09a_uni_avx2_VC2026.zip as on the download page. A successful fetch also increments that file's download count on the site.

Things to watch when updating

  • Leave the contents of the Plugins folder used by Adding formats with KPI plug-ins in place.
  • Leave ffmpeg.exe in the same location as the executable, for Live streaming.
  • Do not delete SongParams.dat, which holds your per-track BPM, key and beat phase.

Supported OS

Windows 11 or later.
