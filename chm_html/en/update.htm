Update checks

Raira checks whether a newer version is available when it starts. If there is something new, a Yes/No dialog appears. Leave Don't ask on, and later launches skip the dialog and keep the choice you made (install, or skip).

When it checks

  • At startup. If a newer build exists, the confirmation dialog appears.
  • Periodically while the program stays open. That path only notifies — it never installs in the middle of playback.
  • When you press Check for update in Rendering settings. Don't ask on or off does not matter; if a newer ZIP exists, the same dialog appears.

The confirmation dialog

You get Yes / No and a Don't ask next time checkbox. The checkbox starts on.

  • Yes — install now. If Don't ask is on, the next launch installs automatically when a newer build exists.
  • No — skip this time. If Don't ask is on, later launches also skip.
  • Uncheck Don't ask, then Yes or No, and the next launch will ask again.

Change it from Rendering settings

The bottom of Rendering settings has the same controls, any time.

  • Don't ask — uncheck it and the next launch will ask again.
  • Yes / No — whether later launches auto-install or skip.
  • Check for update — look at the official ZIP right now. If a newer build exists, "(update available)" appears next to the button.

Periodic checks never auto-install, even when Don't ask is on and the answer was Yes. Swapping files mid-song would stop playback.

The ZIP used by automatic update is the same oggYSEDbgm09a_uni_avx2_VC2026.zip as on the download page. A successful fetch also increments that file's download count on the site, except when this installation already counted an automatic update within the past day.

Things to watch when updating

  • Leave the contents of the Plugins folder used by Adding formats with KPI plug-ins in place.
  • Leave ffmpeg.exe in the same location as the executable, for Live streaming.
  • Do not delete SongParams.dat, which holds your per-track BPM, key and beat phase.

Supported OS

Windows 11 or later.
