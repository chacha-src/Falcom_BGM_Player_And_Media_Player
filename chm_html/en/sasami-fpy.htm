SASAMI .fpy commands (complete)

Every command kbsasami accepts in classic .fpy (OPNA / OPN / BEEP). See SASAMI Composer for how text and staff become opcodes. Nested loops and Misao PCM are in the .fpy2 delta.

File layout

Ten word pointers at the start (absolute 0x1xxx; unused 0x10F0). versionWord at 0x1C is 0 for classic. 0x1E = 0xFFFF means OPNA 10ch. Title / composer / comment are Shift-JIS from 0x50, 64 bytes each. The stream is 3-byte commands from about file offset 0x100.

  • Pointer 0 or 0x10F0, or jump to 0xF0, ends the channel.
  • FNEIRO (cmd2) operands 0xFE00|index are patched to 25-byte voice blocks at the end of the file.
  • Playback chip: playlist “SASAMI FM mode” or kbsasami.fmmode (0=BEEP, 1=OPN FM3+SSG3, 2=OPNA default).

Channels

Internal index is 0-based. Text #n is 1-based (#1 = ch0).

InternalTextRole
0..2#1..#3FM 1–3 (YM2608 bank 0)
3..5#4..#6SSG A/B/C; volume 0..15
6#7Rhythm (OPNA $10; idle on BEEP/OPN)
7..9#8..#10FM 4–6 (OPNA bank 1; unused on OPN)

Tempo

cmd9 T means one tick = hostRate × T / 1248000 samples. T=0 uses the default. Composer t120 / T120 convert to this T.

Opcodes (complete)

Three bytes [cmd][b1][b2] unless noted. w1 is little-endian.

cmdNameOperandsEffect
0FNOTEb1=note, b2=waitKey-on FM/SSG. High nibble=octave, low=name. Rhythm channel waits only.
1FKYUb2=waitKey-off rest.
2FNEIROw1=voiceBuilt-in 0..31 or absolute address of a 25-byte voice. Composer @n.
3FJUMPw1=destJump. 0xF0 ends. Composer J.
4PSGVOLb1=0..15SSG volume. v on #4..#6.
5NEXTF—Skip 3 bytes (compat stub).
6PSGANDreg, maskAND SSG register.
7PSGORreg, bitsOR SSG register.
8FMOUTreg, dataDirect YM write.
9FTMPOw1=TTempo. t / T.
10FSLRb2=waitWait without key-off. Composer @FSLR.
11FVOLb1=YM TL0=loud, 127=silent. FM v.
12FPICHb1=A4, b2=A0F-number (not little-endian).
13loop startb1=count|:n. Classic players expect one nest.
14loop endw1=backDecrement; jump back; key-off first. :|.
15PPICHperiodSSG period.
16FLRLR maskStereo $B4 high bits. @FLR.
17F2JPdestFJUMP only if OPNA 10ch.
18FDETUNw10x8000 = centre. @DETUNE.
19frzmvlidx, volRhythm voice volume.
20rhythm panidx, bits$18+idx high bits.
21FLFO_DPAMS/PMS$B4 low. First half of @LFO.
22LFO enableb1Register $22.
23(reserved)—Classic no-op. .fpy2 uses it for EX.
otherskip3 bytesUnknown commands skip 3 bytes.
