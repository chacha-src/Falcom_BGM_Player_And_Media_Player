CEmu: PC-98

A lookup for PC-9800 zip packs played inside Raira. There is no game screen. How to listen is in Bonus: old-machine sound.

CPU

The classic PC-98 CPU is the 80286 (i286). Every row in this table uses that one CPU.

Sound chips

The routes are FM OPN / OPNA, and the MIDI modules GS / SC-88. The playlist right-click menu only offers the routes that zip actually has.

ColumnPartWhat it is
OPNYM2203PC-9801-26 style: 3 FM channels plus SSG.
OPNAYM2608 (86 board)6 FM channels, SSG, and ADPCM. Catalog rows marked 86 or OPNA land here.
GSRoland GS (SC-55 family)midiout packs sent to a GS module.
SC-88Roland SC-88 familyThe same MIDI output, voiced for SC-88.

The table lists only zips that have been confirmed to play. A catalog entry that is not here still will not play. A circle is a route confirmed for that zip. A dash is not confirmed. Beep and Sound Orchestra stay in Notes. GS and SC-88 are MIDI outputs, but no confirmed PC-98 pack is midiout yet, so those two columns are dashes for now. FM TOWNS packs whose catalog row is pc98vx use this same 80286 and OPNA and appear in this table.
