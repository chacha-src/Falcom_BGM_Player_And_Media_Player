Playing .mid through a VST

You can play .mid (.midi / .kar / .rmi) from the playlist through a VST such as SOUND Canvas VA or S-YXG50. This is separate from the live Playing instruments with the VST host: here the goal is “play the song file through a VST.”

MIDI inputs and parts in the VST host

Setup (Rendering)

  1. Open Rendering settings.
  2. Under MIDI playback, choose Prefer VST (Prefer KPI will not use this path).
  3. Set GS VST to a GS module (SC-VA, etc.).
  4. Set XG VST to an XG module (S-YXG50, etc.).
  5. Use Rescan if needed. A “Searching for VST plug-ins…” wait may appear.

GS or XG?

  • If the SMF contains XG System On → XG VST
  • Otherwise → GS VST
  • If only one side is filled, that side covers both.
  • If both are empty, playback falls back to the Windows MIDI Mapper (or the device chosen under MIDI out).

Play a file

  1. Add a .mid to the playlist and play it.
  2. A banner like file:mid VST (32) or file:mid VST (64) means VST playback. Without a DLL you may see file:mid MIDI Mapper.
  3. Once playback (or a Continuous-play crossfade soft-open) starts, a green LR (or similar) mark appears on the playlist row. MIDI cannot be peeked from the header alone, so the channel count is confirmed when the file is opened.

Watch while it plays

Open the MIDI monitor to see all 32 parts live. Side by side with the piano roll, you get both notes and channel state.

64-bit modules

The player is 32-bit, so 64-bit VSTs go through KpiHost64.exe. If you see “Could not open the x64 VST host. Check KpiHost64.exe.”, make sure KpiHost64.exe is in the same location as the executable. Same idea as Adding formats with KPI plug-ins.
