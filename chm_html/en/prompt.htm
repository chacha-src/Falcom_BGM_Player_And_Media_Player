Automating a performance with prompts

The performance prompt lets you write down moves in advance — "from thirty seconds, push the tempo up; by a minute, deepen the reverb" — and the sound follows your script as it plays. Think of it as a score for the effects.

Opening it

Use the Prompt button on the media player.

How to think about writing it

Each line says when, what and how much. Because it is plain text you can edit, a script that works well can be copied and reused on another track.

  • Pitch, tempo and the various effects can all be driven.
  • Values in Equalizer and environmental models can be moved too.
  • Adding lines builds up a piece of direction that follows the track.

Letting Raira draft it

Raira can analyse a track as it reads it and produce a first draft for you. That means you do not have to write everything by hand — start from the automatic version and correct the parts you disagree with.

History and atmosphere modes

  • Scripts can be saved and loaded again later. Keeping a few variants per track is quite practical.
  • Atmosphere modes let you specify a broad feel rather than writing detail line by line.

If you would rather see it

When text is not your thing, use Laying commands out on the roll, where commands become blocks you place on a timeline, in several lanes if you like.

Baking it into a file

Tick "Apply prompt execution" in Audio export (WAV / mp3 / FLAC) and the whole performance is rendered into the exported file — useful for sharing or for playing elsewhere.

Tip

If you prefer working by hand, Playing with the DJ pad is your tool. The prompt is "decide now, let it run"; the DJ pad is "do it in the moment". Using both covers a lot of ground.

Please note

Large moves can make the sound coarse. Rather than jumping to extreme values, work up in small steps.
