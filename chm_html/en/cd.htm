The CD player

Open it with the always-on CD button on the media player's bottom row, between VST and Maze. Read a disc's TOC, listen, fetch titles from MusicBrainz, GnuDB and others, rip to WAV / MP3 / FLAC, and burn audio or data discs, all here.

Opening it

Press the permanent CD button on the media player's bottom bar (between VST and Maze). The command palette also has "CD player". Position and size are remembered.

Playback

  1. Pick an optical drive and press Load to read the TOC. CD-TEXT is applied here when the disc has it.
  2. Double-click a track or press Play. This uses its own waveOut, so the main playlist keeps going. The main equalizer (including surround) always applies; when upscale is on, a dedicated upscaler matches rate / channels / bits. RubberBand applies when the tempo/pitch sliders are not at 100%. If playback crossfade is on, tracks join at the boundary. The spectrum analyzer and piano roll also receive the PCM while it plays.
  3. The seek bar is a range slider. A / B / A-B× beside it set an A-B loop ([ and ] do the same; press again to clear). Drag the thumbs to move the span. Volume, repeat and shuffle sit along the bottom.
  4. Eject opens the tray. Inserting another disc is picked up automatically.

Titles and cover art

Lookup asks MusicBrainz by DiscID, then GnuDB, iTunes, Deezer and CDStub. Pick from the candidate list. Type a query and press Go for a name search. Cover art comes from Cover Art Archive when a MusicBrainz release ID is present. Needs a network.

Once you apply a match, it is remembered in the TEMP folder for that DiscID. Putting the same disc back uses the cached titles and cover without going online, if the file is still there. If the file is gone, lookup runs again and the candidate list appears. Go (name search) always fetches and never uses the cache. Picking another match overwrites the cache. Clearing TEMP brings the list back next time.

Editing names

Album and artist next to the cover can be typed directly. Track title and artist in the list open with a second click on the selected cell, or F2. Copied text can be pasted onto every selected row. A tab-separated pair fills title and artist together. The list also has an ISRC column when the disc provides codes. Rip filenames use the names you leave here.

Ripping

Format
WAV (uncompressed), MP3 or FLAC. Quality is kbps for MP3, compression level for FLAC.
Rip selected
Writes each selected track to its own file.
Rip all
Writes every track to its own file.
Rip as one
Writes from the first track through lead-out into a single file. If WAV-export crossfade is on, track boundaries use the same join as a multi-select export.
Add to playlist
Appends the finished files to the current playlist.

Sectors are read twice and retried on mismatch. Use ... to choose the destination folder. Rips bake in the current main-player settings (equalizer, surround, upscale, tempo/pitch). When WAV-export crossfade is on and two or more tracks are included, they are joined into one file. The analyzer and piano roll also receive PCM while ripping. MP3 is limited to 2-channel 16-bit, so 5.1-style channel expansion is for WAV / FLAC.

Burning and erase

  • Audio CD — selected WAV / MP3 / FLAC become PCM and burn Track-At-Once.
  • Data CD — files burn as a data track.
  • Erase RW — blanks a rewritable disc. This cannot be undone.

Right-click

Drive, playback, rip (by format), burn, lookup and help sit in submenus. Related commands are nested one level deeper. Follow main keeps this window attached to the main player as it moves.

The ? guide

The ? button shows a Soft3D waveform demo and a Soft2D disc drawing of play and rip. Layout accounts for the acrylic caption height, so controls are not covered.

Tip

Ripping stops CD playback. The main player is left alone.

Please note

No drive, a non-audio disc, or a read error is explained on the status line.
