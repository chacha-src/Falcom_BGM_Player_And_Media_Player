SASAMI MML (MICP standard)

MICP text from the Windows SASAMI help SASAMIM.HLP (2000): notes, parts, standard commands, drums, and short samples. @ / $ and the pitch table are extended commands. How text becomes a file is SASAMI Composer.

Pitch and length

Octaves run from 1 (lowest) to 8. Default is 4. A number after a note overrides L for that note only. C4 is the same as L4C.

TextPitch
CC
C+ or D-C# / Db
D E F G A BD E F G A B
+ / - on a namesharp / flat of that step

The old help noted E+ (F-) as F. Composer treats + / # as +1 semitone and - as −1. On MIDI, o4 C is note 60.

In the old help, & after a note forces the gate to maximum, and the next same pitch becomes a tie. Composer extends the previous note for both & and ^.

Parts

[part:work] starts a channel. Work may be omitted. Work numbers are 1–63 and must not be reused.

  • 1–16 — MIDI port A.
  • 17–32 — MIDI port B (the old help disabled this outside 32-channel mode).
  • Chords use the same part with a different work number.
[2:1] C4
[2:2] E4
[2:3] G4

That is a C major chord. Composer also accepts #n (1-based). Comments run from ; to the end of the line, or //.

Please note

The old help forbids nesting |: and ｛:. Composer allows it: one level stays .mpy / .fpy; two or more becomes .mpw2 / .fpy2.

Drums (lowercase)

Length follows L. The old help also says a known note number can be written as a normal note, and that s matches O3C.

LetterInstrumentNow
h / s / bclosed hat / snare / bassnotes 42 / 38 / 36
o c l m fopen hat, cymbal, low / mid / high tomno dedicated letters (they collide with octave, C, length, or F)
rnot in the old tableride 51 on a drum part

The old switch is @D. Composer uses @DRUM 1, and MIDI 10 / 26 start as drums.
