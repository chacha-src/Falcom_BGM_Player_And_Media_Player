Adding formats with KPI plug-ins

Unusual audio formats that Raira cannot read on its own may still play if you add a kpi plug-in written for Kb Media Player. Legacy kpi plug-ins and some of the newer ones are supported.

Installing one

  1. Put the kpi plug-in file into the Plugins folder next to the executable.
  2. Restart the program.
  3. Open the plug-in list (the kpi list) and check the plug-in you want.
  4. Try playing a file in the format it handles.

Using the kpi list

  • Typing an extension filters the list as you type. Type "mid" and only the MIDI-related plug-ins remain.
  • Checkbox state is kept per plug-in, so you can say "read this track with this plug-in".

How the 64-bit build handles them

The 64-bit build loads plug-ins through a separate process called KpiHost64. That is what allows old plug-ins built for 32-bit to be used from a 64-bit host. 64-bit plug-ins in Playing instruments with the VST host use the same mechanism.

Plug-ins that need extra setup

  • KPI ver5 parameters — detailed settings for the newer plug-in type.
  • fmpmd.kpi PVI path — tells the plug-in where its extra data files live.

A note about exporting

Tracks played through a kpi plug-in sometimes have no known duration. Fill in the length in seconds in Audio export (WAV / mp3 / FLAC) to say how much to write.

Tip

Check Supported formats and titles first. If Raira reads the format natively, you do not need a plug-in at all.

Please note

kpi plug-ins are third-party software and some simply will not work. When one does not, try a different plug-in for the same format.
