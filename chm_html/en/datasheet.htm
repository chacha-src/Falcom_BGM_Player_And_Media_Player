Support datasheet

One page for which game soundtracks loop the way they do in game, and which engine reads everyday audio. CEmu (CPU emulation) is not in this table — see PC-98, PC-88, X68000, X1, MSX, FM-7, PC/AT, and Arcade.

The player, and the process beside it

The player itself is x64. It used to be x86 (32-bit). The helper that loads the other bitness is now the x86 program ogghost32.exe. That job used to belong to the x64 KpiHost64.exe.

  • 64-bit VST and KPI plug-ins load directly in the player.
  • 32-bit VST and KPI plug-ins, and Winamp / XMPlay / AIMP input plug-ins, start ogghost32.exe and talk to it over a named pipe. Keep that exe next to the player.
  • Live VST notes and audio do not travel through the pipe. They use shared memory. The pipe is only for load, unload, and the editor.

&lt;x86&gt; and &lt;x64&gt; after a plug-in name are its bitness. See Adding formats with KPI plug-ins and Playing instruments with the VST host.
