Playing instruments with the VST host

The VST host loads your VST instruments so you can play them live from a MIDI keyboard. Open it with the media player's bottom-bar VST button. To play playlist .mid files through a VST, see Playing .mid through a VST instead.

VST host with plugins and part assignment

From zero to sound

  1. Press VST on the bottom bar. Plug-ins are on the left; Parts 1–32 on the right.
  2. If the list is empty, use Rescan (or right-click → Rescan plug-ins). Only plug-ins that can actually land on a part are listed.
  3. Drag a plug-in onto one of Parts 1–32.
  4. Choose MIDI In 1–2 for keyboards. Each device appears twice: 1-16ch (parts 1–16) and 17-32ch (parts 17–32). Put one keyboard on 1-16ch and another on 17-32ch to split banks, or assign the same device to both to reach 32 parts like Super-MPU. The third slot is Main-playback thru: whatever the player is sounding (any format) is routed here as PCM. While thru is on, the player's own speakers are silent and you hear only this host's audio output. If it is MIDI, the SMF also merges with the keyboards.
  5. Play the keyboard — that part should sound.

Main controls

Preset
Save / switch / rename / delete wiring and device choices.
Rescan
Rebuild the plug-in list.
Save / Rename / Delete
Preset management.
Filter
Narrow the list by name.
Volume
Master level for this host. It scales the whole mix (keyboards, VSTs, and main-playback thru) and the same gain is written to WAV out.
WAV out
Writes this host's mix as 44.1 kHz / 16-bit / stereo WAV. With main-playback thru on, the player's PCM is included. Press again to finish the file. Over 2 GB it becomes RF64.

MIDI In 1-16ch / 17-32ch

MIDI In 1 and 2 list each device as name 1-16ch and name 17-32ch. 1-16ch feeds Parts 1–16; 17-32ch feeds Parts 17–32. Use that to split two keyboards by bank, or assign the same device to both inputs so one keyboard reaches 32 parts (Super-MPU style). Super-MPU devices whose name contains MPU also forward 1-16ch to 17–32 automatically, and honour F5 cable-select. The wiring canvas right-click menu has the same MIDI In 1 / 2 submenus.

The third input is not hardware: it is Main-playback thru. Whatever the media player is sounding (mp3, KPI, video audio, and so on) arrives as PCM and mixes with this host's VSTs. When the file is MIDI, that SMF also merges with MIDI In 1 and 2. WAV out records that mix. While thru is on, the player's own speakers are silent; sound comes only from this host's audio output.

Slot actions

  • Slot button — open the plug-in's editor window.
  • ▼ — choose send channel or program / kit.
  • Right-click — Open editor, MIDI channel to send (as received / ch1–16), program/kit, clear slot, rescan, save preset.

Computer keyboard

Without a MIDI device you can still play: lower keys ≈ C4, upper ≈ C5. Space sends all notes off. Disabled while a text field has focus.

Multitimbral modules

SOUND Canvas VA, SGP2, and similar modules take 16 channels in one slot. MIDI channels pass through, so each channel can be a different instrument.

64-bit plug-ins

64-bit plug-ins load through KpiHost64 — same idea as Expanding formats with KPI plug-ins.

Tip

No MIDI gear? Try the piano tab in Controlling from a phone or PC. To watch SMF channel state, open the MIDI monitor.

Please note

“This plug-in has no editor window” means the UI cannot open — sound still works.
