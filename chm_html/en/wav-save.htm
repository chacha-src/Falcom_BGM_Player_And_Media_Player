Saving to WAV

Save to WAV writes the audio to a file while it plays. It covers both conversion from the Falcom BGM screen and capturing whatever you are listening to in the media player.

Converting from the Falcom BGM screen

  1. Choose a track on the Falcom BGM screen.
  2. Select the WAV output command.
  3. Set the loop count and fade-out.
  4. Choose where to save, and run it.

For mp3 or FLAC, use Audio export (WAV / mp3 / FLAC) on the media player screen instead.

Recording as you listen

Switch Save to WAV on and play: what you hear is written to the file. Stopping playback finalises the file.

Mixing in a microphone

While Save to WAV is on, microphone input can be mixed into the audio being written — sing along, or add commentary.

  • Pick the capture device in Rendering settings.
  • The mix level runs from 0 to 200%.
  • You can toggle it from the media player playlist right-click menu as well.
  • To change how your voice sounds, combine it with The voice changer.

Together with crossfade

With Continuous-play crossfade on, this becomes a verification dump.

  • Everything is appended to a WAV named after the first track you played.
  • The output is fixed at 96 kHz / 2ch / 24-bit, converted from the mix you can hear.
  • Stopping playback finalises the file.

Large files

Anything beyond 2 GB is written as RF64, so length is not a problem.

Tip

If what you want is not "the audio I am playing" but "everything coming out of my speakers", Recording what you hear is the better fit — it picks up other programs too.

Please note

For sound coming in from outside, such as records or cassettes, use The analog digitizer, which adds noise control.
