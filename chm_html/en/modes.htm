The two screen modes

Raira has two screens with quite different personalities. Both use the same playback engine, so your sound settings and equalizer carry across. Choosing one is not a commitment, and there is very little to re-learn either way.

Example of the media player screen

The Falcom BGM screen

A dedicated screen where tracks are listed per game title. Its big feature is playing each track with the exact loop the game uses, and it is also where WAV conversion lives. See The Falcom BGM screen.

The media player screen, "Raira"

A regular media player: build playlists, queue what you like, play it. Almost every feature in the program lives here — the elaborate seek bar, lyrics, the analyzer, the piano roll, recording, streaming and the DJ tools. Reading onward from A tour of the media player screen gives you the whole picture.

Switching

  1. Close the program.
  2. Start it again. The startup-mode dialog appears; pick the screen you want.
  3. No dialog? Then "Ask again next time" is switched off. You can restore the prompt from Rendering settings.

Shared no matter which you choose

  • Your Equalizer and environmental models settings
  • Rendering settings — playback device, bit depth, language, file associations
  • The look you set in Acrylic look and context menus
  • How Update checks behave
Tip

Move the main window and related windows such as the equalizer and analyzer follow along. If you would rather place one somewhere on its own, turn off follow-lock in that window's right-click menu.
