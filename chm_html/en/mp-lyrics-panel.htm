The in-player lyrics panel

Inside the media player there is a panel that scrolls lyrics along karaoke-style. It is independent of the separate lyrics window, and suits the case where you want lyrics without another window on screen.

Getting lyrics to appear

  1. Put a .lrc file with the same name next to the track. No file? Raira can fetch one — see Showing lyrics.
  2. Switch the lyrics panel on in the media player.
  3. Play the track. The current line scrolls to the middle of the panel.

How it differs from the lyrics window

In-player panelLyrics window
Where it livesInside the media playerIts own separate window
Always on topMoves with the main windowCan stay above everything
AppearanceFits the panel sizeRemembers opacity, line count, font and position
Best forWatching the player as you listenLyrics while you work on something else

The lyrics window opens from the right-click menu on the arrow beside the Lyrics button.

When the timing is off

If lyrics run ahead of or behind the music, you can shift the timings in steps of ±10 ms, ±50 ms and ±100 ms, then save the result to the file. Showing lyrics has the details.

Tip

Each lyric line's timing also appears on the seek bar as a thin cyan line. Click one to jump to that line, which makes "just the chorus" a single click away. See Reading the seek bar.

Please note

With no lyrics file, the panel simply stays empty. Online lookup also depends on a sensible title and artist, so tidying those up in Editing tags first improves your odds.
