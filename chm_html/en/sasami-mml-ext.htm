SASAMI MML extended commands

Extended commands from SASAMIM.HLP. They start with @ or $. Notes and standard commands are MML (MICP). Commands marked exclusive should be followed by at least a 16th to a 64th of rest, per the old help.

Please note

The last column is the current text Composer. “skip” drops the command and its arguments. A number after @ is a program, @V is volume, @P is pitch, and @R / @r are stored as the same three-integer command. $ commands are written as MIDI. A $ that is not a command is still a separator. Named forms @PROG @BANK @CC @DRUM belong to Composer, not to these one-letter commands.

Tone tweak

The old heading is a parameter index and a value after @. n is 0–7, m is 14–114 (64 = 0). A number after @ is a program in Composer, so this tweak is not stored as a tweak.

@ exclusive and CC

One line, two hex digits. Commas or spaces optional. The compiler appends the checksum and F7. Do not put FF in the data (it is the end marker).

  • @(10,20,30,40,50,60,7F,1F) — GS. F0 41 10 42 12 is added. Write address and data only.
  • @(M01:F0,41,10,45,12:10,00,00,35,35) — mode filter. 0=55/88Pro, 1=88, 2=XG. Combine digits. Split header and address with :.
  • @(B01,30) — CC. Bn is added. This example is modulation 0x30.

Composer does not accept @(. Use @EX for SysEx and @CC for a control change.

$ commands

Composer emits these as velocity, CC, or GS/XG SysEx. $M stops the rest of that part at playback when the tone-map matches. The TIME field of $CG has no GS address, so it is accepted and not sent. A $ that is not one of these commands is still a separator.

CommandMeaning
$(n / $)nVelocity −n / +n from @N, 1–99. No clamp. Example @N100 C $(20 C.
$M nDo not emit on that mode. 0=55, 1=88, 2=XG, 3=GM. $M0$M1 blocks 55 and 88.
$L / $l88Pro legato on / off. Example C $L DEFGAB $l.
$I n88Pro EFX 0 off, 1 on.
$(I n:…)88Pro EFX type 0–64 and parameters from the low index. Blank fields keep the default. Wrong counts are errors. Afterwards $+ and $# map to CC16 and CC17.
$+ n / $# nEFX + / # parameter, 0–127, default 0.
$RG $CG $VGGS reverb, chorus, delay (delay needs 88 or later). Decimal. Skip a field with ,,.
$RX $CX $VXXG reverb (13 params), chorus (10), variation (count depends on type). Two hex digits. Type 0 is illegal. Stick to 1–8 / 1–8 / 1–38 for plain XG.

Pitch numbers

The old help calls one semitone 341.333 Hz and the center 8192 Hz. Those numbers are @P units, not acoustic hertz. 8192 is center C.

semitones  +24    +12     0     -12    -24
@P        16383  12287   8192   4095    0
one step is about 341.33   +1 = 8533    -1 = 7850
