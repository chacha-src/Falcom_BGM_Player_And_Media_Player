Pointing Raira at your game folders

The folder settings window is where you tell Raira which folder each game lives in. The standard install path for every supported title is filled in already, so a normal installation is usually found automatically. Fix this up if, say, you keep your Steam library on another drive.

Setting a folder

  1. Open the folder settings from the Falcom BGM screen.
  2. Find the row for the game you want to fix.
  3. Use the browse button to select the game's folder — normally the folder that contains the game's executable.
  4. Save and close, then select that game again on the Falcom BGM screen.

When a game will not turn up

  • Steam titles live under steamapps\common\GameName.
  • Point at the game's own folder, not the subfolder holding the audio data (bgm, voice, data and so on).
  • Non-ASCII characters in the path are fine.
  • Games on an external drive stop being found when the drive letter changes. Just set the folder again.

Titles that need the WAV files copied

Brandish 4 and the Gagharv Trilogy (White Witch, A Tear of Vermillion, Cagesong of the Ocean) play from WAV files copied off the disc.

  1. Copy the WAVE, WAVEDV or WAVEDVD folder from the disc to anywhere on your hard disk. The name varies by game.
  2. Point the folder setting at that copy.
Tip

Once everything is found, drag your favourite tracks into a playlist. From then on you can reach them quickly from the media player screen, and Raira will remember per-track volume and EQ too.

Please note

If a game still produces no sound after you set its folder, it may simply not be supported yet. Check Supported formats and titles.
