Showing lyrics

Load a timed lyrics file (.lrc) and the words follow the music. If you do not have one to hand, Raira can look one up online.

Placing a lyrics file

The simplest arrangement is a .lrc file with the same name, in the same folder as the track.

Music\
  +- 01 - Silver Will.ogg
  +- 01 - Silver Will.lrc   <- same name

Fetching lyrics online

  1. With the track playing, run the lyrics lookup.
  2. Raira searches sources such as LRCLib and NetEase.
  3. Anything found is loaded and ready to display.

Lookups depend on a sensible title and artist, so tidying those up in Editing tags first raises your success rate considerably.

Two ways to display them

The in-player panel
Scrolls karaoke-style inside the media player. See The in-player lyrics panel.
The lyrics window
A separate window that can stay above everything else. It remembers opacity, the number of visible lines, the font and its position, which makes it ideal for reading lyrics while you work on something else. Open it by right-clicking the arrow beside the Lyrics button.

Fixing the timing

When the lyrics run ahead of or behind the music, you can shift every timing at once.

  • ±10 ms for fine tuning.
  • ±50 ms for ordinary drift.
  • ±100 ms when it is clearly out.
  • Save to the file once it lines up, and it will be right from then on.

How this ties into the seek bar

Each line's timing appears on the seek bar as a thin cyan line. Click one to jump to that line, which turns "start from the second chorus" into a single click, and gives you natural candidates for A-B ranges. See Reading the seek bar.

Tip

To make lyrics easier on the eye, try a larger, more readable font via Acrylic look and context menus.

Please note

Plain text lyrics with no timings cannot be scrolled in sync. A timed .lrc file is what makes this feature shine.
