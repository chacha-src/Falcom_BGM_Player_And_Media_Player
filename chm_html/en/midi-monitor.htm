MIDI monitor

The MIDI monitor watches the SMF that is playing (.mid / .midi / .kar / .rmi) as 32 parts (A01–A16 / B01–B16). It shows what is written in the MIDI file, not notes guessed from audio. Where the piano roll shows notes over time, this window lists each part's tone, level, and effects.

MIDI monitor

How to open it

  • Always-on MIDI button between VST and CD on the media-player bottom bar (stays depressed while open)
  • Media-player banner right-click → Window → MIDI monitor…
  • Playlist right-click → Window → Open MIDI monitor
  • Seeing notes on the piano roll / analyzer / EQ right-click → Open → MIDI monitor
  • VST host wiring canvas right-click → Open MIDI monitor
  • Command palette: “MIDI monitor”
Tip

Position and size are remembered for the next open.

Header

  • BPM, tempo %, key, time base, meter, transpose, file name (sequence name beside it when present; a name that is only "???" is omitted)
  • DS volume %, note count, DRUM
  • To the right of DRUM: current bar/total (001/051), beat/beats-in-the-bar (1/4→2/4→3/4→4/4), tick-in-bar / ticks-per-bar (0000/1920). They follow the play position. If the meter changes, the beat denominator follows it.
  • Reverb / chorus / variation
  • SYS (GM / GS / XG), INSERTION 1 / 2 (official names such as Thru, Distortion, Over Drive — not ON/OFF. XG insertion, Variation when connected as insertion, or GS EFX)

The 32-row channel table

Each row is one part. The top 16 rows are the first half; the bottom 16 are the second. Drums follow the song (channel 10 is not always drums). During VST playback, GS Reset is followed by rhythm mode on A10/B10; XG songs get a drum bank on channel 10. See Playing .mid through a VST.

While catching up, only the last SysEx per address and the last CC of each type are applied. A dump that walks all 32 channels several times is collapsed to the latest state at the play position.

Every 16ms only rows whose picture changed are repainted: a bar when it moves by a pixel, the mini keyboard only when the held notes change. Even with all 32 parts sounding, the table is not fully repainted.

PC# / BNK / Map / Instrument
Program, bank, GS/XG map, and instrument name (from the built-in SASAMI GS/XG tables).
Lev / Vol / Pan / Exp
Output level plus volume, pan, and expression. The bars are narrow, so the titles use two rows like Vibrato Rat/Dpt, alternating up and down.
Rev / Crs / Var
Reverb, chorus, and variation send amounts.
Vibrato / Filter / Envelope / EQ / NRPN
Live controller / NRPN state for those areas. Headings share the same X as the numbers below.
Keyboard (mini keys on the right)
Keys that are down light up. Click a key to play that part through the current playback path.

Colors

  • Channels that have not yet received a note, CC, or SysEx stay gray. Clicking a mini key to play restores the white / off-white stripe.
  • Drum parts tint the whole row (CH#, name, parameters, and keys) a warm color.
  • PC# / BNK / Map keep the row stripe while notes play. Sounding is shown on the mini keyboard and Lev bar.
  • An instrument change ambers that cell. Meter bars do not fade.

Playing from the mini keyboard and sliders

Clicks on the mini keyboard and drags on volume actually reach the sound, not just the display. During Playing .mid through a VST, they enter the same module as the song. Clicking a key does not rewind the song. When playback uses Windows MIDI, the same output is used. During Adding formats with KPI plug-ins MIDI playback, keys go to the MIDI-out device in Rendering.

View modes (2D / Soft 3D)

  • Normal (2D) — table layout with thin lines between parts; the default.
  • Soft 3D — 32 part levels as boxes, drawn on the CPU only (no OpenGL / Direct3D). Drag to orbit, wheel to zoom, 0 to reset. Switch back to 2D from the right-click menu if it feels heavy.

Timing vs what you hear

When playing through Playing .mid through a VST, note display may lag slightly so it stays close to the audible position (plugin latency and output lead). Until the first note appears, SysEx/CC are not delayed so an opening dump is not dragged by that lag. After the first note, SysEx/CC follow the audible position too.

How it relates to other features

  • Seeing notes on the piano roll — notes over time; the monitor is channel state.
  • Playing .mid through a VST — watch GS/XG VST playback here.
  • Playing instruments with the VST host — live keyboard hosting. Opening the host links its MIDI in and mini keys to this monitor.
  • Controlling the player with a MIDI keyboard — map transport / EQ to hardware.
Tip

Press ? for the in-window guide. See also The “?” guide on every window.

Please note

Audio files (mp3 and so on) have no MIDI events, so the monitor stays idle. Use it during SMF playback, or when the VST host is taking keyboard / MIDI in.
