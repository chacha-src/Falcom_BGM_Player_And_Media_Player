MIDI monitor

The MIDI monitor watches the SMF that is playing (.mid / .midi / .kar / .rmi) as 32 parts (A01–A16 / B01–B16). It shows MIDI events from the file, not pitches guessed from audio.

How to open it

Right-click the media-player banner and choose Windows → MIDI monitor. You can also open it from the playlist context menu, from Equalizer / Analyzer / Piano roll → Open, or from the command palette.

What you see

  • Header — BPM, tempo %, key, time base, time signature, Transpose, file name.
  • Each part — PC / bank / map, instrument name, level, Vol / Pan / Exp / Rev / Crs / Var, vibrato, filter, envelope, EQ, NRPN, mini keyboard.
  • Instrument names — looked up from the built-in SASAMI GS / XG tables. XG System On selects XG names; otherwise GS. Right-click Tone map to force one map.

View

  • Normal 2D — a table.
  • Soft 3D — 32 part levels as boxes, drawn on the CPU. Drag to orbit, wheel to zoom.

GS / XG instruments

The VSTis used for playback are GS VST and XG VST in Rendering settings. Before play starts, the SMF is peeked: an XG reset (XG System On) selects the XG slot, otherwise the GS slot. If only one slot is filled, that plugin covers both. If both are empty, Windows MIDI Mapper is used.
