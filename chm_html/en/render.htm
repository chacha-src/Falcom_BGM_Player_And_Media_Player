Rendering settings

Rendering settings is the foundation of the program. "No sound", "the audio breaks up", "I want larger text" — most of those are solved right here.

Where the sound goes

Playback device
Which speakers or headphones the audio comes out of. When there is no sound at all, check this first.
Buffer
How much audio is held in reserve. Larger is more robust, smaller is more responsive. If the sound stutters, make it larger.
Bit depth
The resolution of the output. Sample-rate and bit-depth upscaling and multi-channel output are supported.

The microphone device

The capture device used by the microphone mix in Saving to WAV is chosen here.

Appearance

Language
Fourteen locales: Japanese, English, Français, Italiano, Español, 한국어, 中文, العربية, Русский, Deutsch, Português, Nederlands, Polski and Türkçe.
Fonts
Changes the text throughout the program. Set a size you find comfortable.
Spectrum scale mode
How the frequency display is scaled, which changes how the Waveform and spectrum analyzer looks.

File associations

Associate extensions so that double-clicking a file in Explorer opens it in Raira.

  • Audio — mp3, flac, ogg, wav and more
  • Video — avi, mp4, mkv, wmv, mov, webm and more
  • Playlists — m3u and similar

The startup-mode prompt

Whether the "which screen would you like to start in?" dialog appears is also restored from here. See The two screen modes.

MIDI playback and VST modules

MIDI playback (Prefer KPI / Prefer VST)
Choose whether playlist .mid files use KPI or a VST. Details: Playing .mid through a VST.
GS VST
GS module (SC-VA, etc.) for SMFs without an XG reset. If empty, XG side is used; if both empty, the MIDI Mapper.
XG VST
XG module (S-YXG50, etc.) when the SMF has XG System On. If empty, GS side is used.
MIDI out
Hardware / mapper destination when both VST paths are empty.
Rescan
Search again for VSTs under the chosen paths.
Tip

The "?" button opens the render guide, a diagram made for this window, so you can see what each option affects.

Please note

If the app is muted in the Windows volume mixer, Raira warns you at startup. When there is still no sound after checking these settings, check Windows' own volume mixer as well.
