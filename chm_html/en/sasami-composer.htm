Composer Sasami☆Mi

A desk for writing songs, opened from Raira’s Tools menu under Sasami-related composer. It gathers what the old Windows Sasami☆Mi did: writing a song as text, and writing it on a staff. Finished songs play in Raira, and can be written out as WAV / mp3 / FLAC.

The flow

Write as text  ←→  Place notes on a staff  ←→  Piano roll
                        │
                        ▼
         Preview (plays in place; not added to the list)
                        │
                        ▼
      Save the song file   /   Export WAV, mp3, or FLAC

The three windows open separately. If you edit the same song in two of them at once, watch the save path so they do not overwrite each other. Text and the staff go back and forth; a change on one side shows up on the other.

How to open it

Right-click Tools on the media player and open Sasami-related composer.

  • Text compose — write the notes as letters. See Writing in text.
  • MIDI score — a staff. Each part can use an instrument you already have. MIDI score.
  • FM score — the same staff, for FM voices and for parts that play a waveform. FM score.
  • MIDI piano roll / FM piano roll — the same song as blocks on a keyboard. Piano roll.

Placing notes is in The staff. Adding drums and bass is in Auto accompaniment. The save type is in Which file you get.

The detailed text commands stay on the MML pages and after. For everyday writing, the pages in this section are enough.

Preview and export

Preview plays in place and does not add the song to the playlist. Export opens the WAV / mp3 / FLAC window. A song file you save can be added to Raira’s list in the usual way.

Raira’s MIDI monitor can watch a playing FM song as keys and voice state.

Tip

The first time, write a short melody as text and preview it. When you like it, move it to the staff and add accompaniment.
