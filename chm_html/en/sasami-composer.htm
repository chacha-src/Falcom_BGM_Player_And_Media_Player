SASAMI Composer (create songs)

Open SASAMI Composer from the Media Player Tools menu to create Sasami-format songs. This replaces the old Win sasamim workflow.

How to open

In Media Player, open Tools and the SASAMI submenu:

  • Text — MICP / MML3 syntax coloring and compile
  • MIDI score — staff score (tracks / strip / note palette) with VST2/3
  • FM score — same staff shell (FM10 + Misao16); double-click opens the voice editor

Text

Besides the simple dialect (#1, lowercase t120, cdefgab), the same compiler reads legacy MICP / SASAMIM songs: [port:ch], uppercase T tempo, @prog:bank, P/Q/O/L/V, dots, and ^ ties. Comments: ; or //.

@SVIB / @STREM / @SPAN / @SPORTA are compiled into classic pitch / volume / pan waits (an internal ｛: :｝ unroll) so MPY / MPW2 / FPY stay playable on older players. They do not force MPW3/FPY2.

For VST3 songs write @VST"path", @PROG, @BANK and save as MPW3. For FM, start with OPNA or OPN to build an FPY.

MIDI staff score

Place noteheads on multi-track staves. Use pencil / eraser / select, the floating note-duration palette, and the Expression strip. Double-click a track or staff to open that part's VST2/VST3 editor. Without VST binds save MPW2/MPY; with VST binds save MPW3.

FM staff score and voices

Edit FM1–10 and Misao1–16 in the same staff shell. Double-click opens the voice editor; preview, then confirm. The strip defaults to Volume. Voice numbers are assigned automatically.

Preview and audio export

Preview writes a temp file and adds it to the playlist. Use Export to open the WAV / MP3 / FLAC dialog.

Soft FX (always unrolled)

@SVIB / @STREM / @SPAN / @SPORTA become classic pitch / volume / pan waits (FM cmd12/11/16, MIDI cmd11/5/12). The player can still run handwritten FM cmd25/29 and MIDI cmd46/47; Composer does not emit them. They do not change the extension.

Tip

The three windows open separately. Be careful with overwrite if you edit the same song in more than one.
