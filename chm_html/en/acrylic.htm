Acrylic look and context menus

This is where you settle how Raira looks. Make the windows translucent, and choose how right-click menus animate into view. Your choices are saved and apply from the next time a menu opens.

Acrylic blur

Raira can adopt the translucent blur of Windows 11. You do not have to open the settings for it — the Acrylic mode item in the context menu toggles it on the spot.

The Waveform and spectrum analyzer and Seeing the music on a piano roll support acrylic too.

Menu animations

Choose how custom context menus appear and disappear.

  • Classic (fade)
  • Expand up and down
  • Curtain (from the top)
  • Wipe (horizontal)
  • Ripple (spreading from where you clicked)
  • Big Bang
  • Black Hole
  • Spiral
  • Petals
  • Zipper (alternating left and right)
  • Aurora (a wave; the default)

The choice is saved and applies from the next menu you open.

Menu font

The menu font can be set between 8 and 24 pt, in bold or italic if you like. Hovering a candidate previews it, so you can see the real thing before committing.

Changing the text elsewhere

To change the text throughout the program rather than in menus, use the font setting in Rendering settings.

Remembering window arrangements

Layouts 1–3 in The companion tools remember up to three window arrangements — one for working, one for listening properly, and so on.

Tip

When you want more room on screen, try focus mode in The companion tools, which strips the display back so you can concentrate.

Please note

The more elaborate animations can feel sluggish on an older machine. Classic (fade) is the lightest of them.
