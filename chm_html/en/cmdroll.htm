Laying commands out on the roll

The command roll is the visual way to arrange the commands from Automating a performance with prompts. Time runs left to right and lanes stack downwards, so "make this happen at this moment" becomes a block you drop into place.

Opening it

Use the Roll button on the media player (the command roll one).

Placing commands

  1. Click at the time where you want something to happen.
  2. Choose what it does in the command placement dialog.
  3. Drag a placed block later to shift its timing.
  4. Use separate lanes to make several things happen at the same moment.

Keeping it readable

Zoom level
Stretch out horizontally for fine timing, or shrink to see the whole track. The zoom is remembered, so it looks the same next time you open it.
Follow the main window
With the lock on, the roll moves when you move the main window. Turn it off to place the roll independently.
Multiple lanes
Putting tempo moves and effect moves in separate lanes makes the overall shape much easier to read.

Moving between roll and text

The roll and the prompt text are two views of the same thing, which lets you sketch roughly on the roll and then tighten up the numbers as text.

Turning it into a file

To render what you have arranged, use "Apply prompt execution" in Audio export (WAV / mp3 / FLAC).

Tip

This window has its own "?" guide — the prompt roll operation guide — with diagrams of how blocks are placed. See The "?" guide on every window.

Please note

The command roll is for arranging automation over time. For hands-on control in the moment, Playing with the DJ pad and Controlling Raira from a MIDI keyboard are the right tools.
