SASAMI .mpy commands (complete)

Commands kbsasami expands from .mpy into SMF. 64 tracks and dual port are the .mpw2 delta; VST binds are the .mpsmv delta.

File layout

  • No leading magic. Version bytes at 0x80/0x81. 0x82=dual port, 0x83=wide (64 tracks if 1).
  • Classic .mpy: 32 tracks, 16-bit pointers (ch32+ at 0x100).
  • Title at 0x160, Shift-JIS 64×3. Stream addresses = file offset + 0x1000.
  • Most commands 3 bytes. cmd13/14/15/37/46/47 are 4 bytes. cmd36/40 variable. Jump dest 16-bit. 0xF0 ends a track.

Map

kbsasami.midimode and the playlist SASAMI source mode pick GS/XG/55/88. Some opcodes use b1 on 88map and b2 on 55map (cmd2/5/7/12).

When Composer writes .mpy

No VST bind, no native ｛:, no @CC family, loop nest ≤ 1. kbsasami can still play cmd41/46/47 inside .mpy. Composer sends @CC songs to .mpsmv and always unrolls @SVIB (never cmd46/47).
