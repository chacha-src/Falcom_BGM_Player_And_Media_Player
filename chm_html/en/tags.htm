Editing tags

Open Edit tags from the playlist right-click menu. This is the tool for knocking a messily named collection into shape, and with several tracks selected it edits them all together.

What you can edit

  • Title, artist, album
  • Year, track number, genre
  • Comment
  • Cover art

Editing one track

  1. Right-click a track in the playlist and choose Edit tags.
  2. Change whichever fields you need.
  3. To change the artwork, select a new image.
  4. Write the tags and the changes are saved into the file itself.

Editing in bulk

Select several tracks and you get the batch editor.

  • Only the fields you fill in are applied to every selected track.
  • Fields left blank are not touched. So if you only want to unify the album name, fill in the album field and nothing else.
  • The classic use is selecting an album's worth of tracks and giving them a consistent album name and cover.

Formats that can be written

MP3, FLAC, WAV, M4A and Ogg Vorbis.

Please note

Encrypted FLAC and writing to Opus are not supported. Writing also modifies the files for real, so it is worth backing up anything precious before a large batch run.

Filling tags in automatically

The MusicBrainz auto-tag tool in The companion tools looks up candidates from the title and artist and applies the results. It does not use audio fingerprinting, so a track whose name is a complete mystery may not be found.

Why tidy tags pay off

  • Online lookup in Showing lyrics becomes far more reliable.
  • Conditions in Smart playlists and the library tree actually work.
  • "Copy tags and cover" in Audio export (WAV / mp3 / FLAC) produces tidy files as well.
  • Controlling Raira from a phone or PC and any stream overlay become much easier to read.
Tip

If you only want to change what Raira displays, without touching the file, edit the display name in Viewing and fixing file info instead.
