Continuous-play crossfade

With continuous play on, Raira can overlap the end of a track with the next one for a number of seconds you choose, handing over smoothly. Just the thing when you want music running all evening, or when the silence between tracks bothers you.

Setting it up

  1. Turn on continuous play in Playing, stopping and volume. This is the prerequisite.
  2. Tick the crossfade box. It is available on the main screen and the media player screen alike.
  3. Enter the overlap in seconds. Decimals are allowed; the default is 5.00.
  4. Keep listening — the next track now comes in over the end of the current one.

How tracks join

  • As the end approaches, Raira quietly soft-opens the next track in the background.
  • For the number of seconds you set, both tracks blend smoothly, so neither drops away and the level does not sag.
  • Once the blend finishes, the next track is promoted to the main stream. The playlist note icon, the jacket and the duration and tag columns all update.
  • Channel marks (green MONO / LR / 2.1…) are also written as soon as the next track is soft-opened. Formats that cannot be peeked from the header alone — VST MIDI, m4a and the like — get the same marks as on a normal play.
  • Video rows and unplayable entries are skipped, continuing to the next audio track.

How this differs from export crossfade

Continuous-play crossfadeExport crossfade
PurposeRemove the seams while you listenJoin tracks into one file
Where it is setA checkbox and duration on the main / media player screenInside Audio export (WAV / mp3 / FLAC)
ResultOnly the sound in the moment changesA file is produced

Capturing the blend

Combined with Saving to WAV this becomes a verification dump.

  • Everything is appended to a single WAV named after the first track you played.
  • The output is a high-quality WAV, converted from the mix you can actually hear.
  • Stopping playback finalises the file.
Tip

For better joins, measure the tempo in Measuring BPM and feed it into the crossfade duration so the beats stay together. Placing a track in a compatible key next is effective too — the key-detect and Camelot compatibility tool in The companion tools lists the candidates.

Please note

During a crossfade Raira renders two tracks at once, which can be a lot for an older machine. If the sound breaks up, try a larger buffer in Rendering settings.
