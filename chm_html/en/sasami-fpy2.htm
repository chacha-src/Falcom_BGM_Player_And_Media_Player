SASAMI .fpy2 — delta from .fpy

.fpy2 uses the same channels and 3-byte commands as classic .fpy. The delta is the version word, nested loops, extra opcodes, Misao PCM, and a macro footer. See .fpy commands for the base set.

Header

  • Extension .fpy2, or versionWord at 0x1C = 2.
  • Loop nest up to 16 (classic expected 1).
  • Optional trailing FPY2MACR for @MACRO.

New or changed opcodes

cmdNameComposer
13/14nested loop|:n nest or native ｛:n ｝:
23EX1–4@EX1..@EX4. SSG EX1=$06, EX2=$07. Classic no-op.
24fhokry legato@LEGATO / @FHOKRY (no key-off)
25soft vib/tremHandwritten files. Composer @SVIB unrolls instead.
29soft portaHandwritten. Composer @SPORTA unrolls.

Misao PCM

Sixteen word pointers at 0xD0. 0xF0=1, 0xF1=channel count. Composer: @PCM"path". Save As copies the sample beside the .fpy2.

cmdEffect
0 / 1 / 24note on (off previous) / rest / legato note
2 / 11 / 25program / volume / pan
3 / 9 / 10jump / tempo / wait
12 / 18pitch bend / detune
13 / 14loop start / end
26skip b2 bytes

When Composer writes .fpy2

  • Loop nest ≥ 2.
  • @PCM, @EX1–@EX4, @LEGATO.
  • Native ｛: in the text.
  • @MACRO / @CALL.
  • @LFO @DETUNE @FLR @FSLR (Composer policy; classic opcodes exist).

On both .fpy and .fpy2, Composer unrolls @SVIB to pitch/vol/pan waits (it does not emit cmd25/29). Nested loops, PCM, EX, and legato cannot be unrolled — they need .fpy2.
