Watching WRD

WRD is the lyric and picture script that shipped with PC-98 MIMPI and TMIDI. Letters and MAG images follow the MIDI position (measures and @WAIT). The sound itself is FM/MIDI monitor or Playing .mid through a VST.

Open it

  • Right-click the media player banner → Window → WRD.
  • Command palette: WRD.
  • If the track that is playing has a WRD script, that script is loaded.

What you see

When a script loads, lyrics and MAG images follow playback. Otherwise the window says there is no WRD. Ordinary mp3 files do not carry one.

Right-click

Always on top
Keep the window above others.
Reload
Read the current WRD again.
Open MIDI monitor
Open FM/MIDI monitor for the same track.
Tip

When a PC-98 MIDI pack is playing from PC-98, a bundled lyric script can sit beside it in this window.

Please note

WRD time uses the SMF tempo map (a quarter note is 48 ticks). Tempo changes in the song are followed.
