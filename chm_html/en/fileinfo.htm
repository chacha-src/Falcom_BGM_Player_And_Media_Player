Viewing and fixing file info

Open File Info from the playlist or media player right-click menu. It shows you the current state of everything about a track, and lets you correct whatever looks wrong.

What you can see

  • The display name, artist and album as shown in the playlist
  • The file's path
  • The tags written inside the file
  • Whether the file actually exists, its extension and its size
  • The loop points
  • Whether per-song settings (the star) are stored

Tag operations

Apply tags to playlist
Reads the file's tags into the playlist's display fields. Use this when the tags are right but the list is showing something stale.
Reload tags
Re-reads the tags from the file.
Write tags
Writes what is on screen into the file. Supported formats are MP3, FLAC, WAV, M4A and Ogg Vorbis.

Finding the file

  • Browse path reselects the file somewhere else — for when you have moved it.
  • Select in Explorer opens the containing folder.
  • Copy path and copy file name put the text on the clipboard, ready to paste into another program.

Loops and per-song settings

  • Loop points can be edited here; pressing OK saves them to the playlist.
  • For finer control you can jump straight to Playback details.
  • Per-song settings (the star) can be cleared from this window when you no longer want them.

Fixing several tracks at once

Select several tracks before opening this window and you can batch-edit artist and album. To change titles, years or genres in bulk, Editing tags is the better tool.

Tip

When files have gone missing, the missing-file review in Working with playlists is faster than fixing them one at a time here — it can correct similar paths together.

Please note

Changing the display name here does not change the file's tags. To alter the file itself, use Write tags or Editing tags.
