SASAMI .mpw2 — delta from .mpy

Stream opcodes are the same numbers as .mpy. The delta is the header, the track table, and nested loops kept native. VST and macros are .mpsmv.

Header

  • Magic EE EE EE plus ASCII SASAMI MPY Ver2.2.
  • Track table at 0x200: 24-bit address + part byte, up to 64 tracks.
  • 0x82 = dualPort (cmd38). 0x83 = 1 (wide). Titles still at 0x160.

Unchanged in the stream

cmd10/cmd24 destinations stay 16-bit (0x1xxx). Only the table is 24-bit. Reading jumps as 24-bit breaks loops.

Nested loops

cmd23/24 stack depth 16. Composer writes .mpw2 when |:n nest ≥ 2.

Dual port

cmd38 sends later events to port 2. Needs 0x82=1. Text [port:ch].

When Composer writes .mpw2

  • MIDI loop nest ≥ 2.
  • No VST, no @CC family, no native ｛:, no @MACRO.

@SVIB family is still unrolled on .mpw2. The player can run cmd46/47; Composer does not emit them.
