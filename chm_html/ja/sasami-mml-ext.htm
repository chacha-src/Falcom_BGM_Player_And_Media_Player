SASAMI MML 拡張命令

SASAMIM.HLP の拡張命令です。頭は @ または $、半角大文字が原則です。音階と標準命令は MML（MICP） です。※ の付く命令は、旧ヘルプでは出したあとに 16分～64分以上の休みを取る、とあります。

注意

右端はいまのテキスト Composer です。「捨てる」は引数ごと読み飛ばします。@ の数字はプログラム番号、@V は音量、@P はピッチ、@R と @r は同じ 3 整数命令として残します。$ の命令は MIDI に出します。命令でない $ だけ区切りとして読み飛ばします。名前付きの @PROG @BANK @CC @DRUM は Composer の書き方で、この表の 1 文字命令とは別です。

@ 音量・音色・バンク

命令範囲初期意味いま
@M n ※0～127127マスター音量。音源全体。捨てる
@N n0～127100ノート音量。出す（ベロシティ。v と同じ）
@E n0～127127エクスプレッション。パート音量を 127 とした微調整。捨てる
@N[:m][:k][:l]1～1281音色。省略なしは n=88、m=55、k=XG、l=GM。全部略すと 55/88/XG/GM が同じ番号。k だけ略すと n=88、m=55、XG と GM は m。Lv2 は @88Pro:88:XG:GM。例 @10、@5:8、@1:2:3。@数字 と @数字:数字 はプログラム
@V n[:m][:k][:l]0～127117トラック音量。m と k の省略は音色と同じ。出す（最初の数）
@B n[:m][:k][:l]0～1270バンク（CC0）。音色のあとでは効かない。先にバンク、次に音色。捨てる。@BANK
@~ n0～1270モジュレーション。大きいほど振幅が大きい。捨てる

@ ピッチ

絶対値は 0～16383、中央 8192。旧ヘルプは 4 オクターブ分、としています。半音の数値は下の表です。相対変化は 16383 を超えず、0 を下回らないように、とあります。

命令範囲初期意味いま
@P n0～163838192ピッチベンド絶対値。出す
@^ n0～—いまの位置から n だけ上げる。展開ループと組む。例 C4 ｛:48 @^4 ^64 :} は 4分のあと、付点2分のあいだ 64分ステップで 4 ずつ上がる。捨てる
@v n0～—n だけ下げる。例 C4 ｛:48 @v4 ^64 :}。@v は音量になる

@ ドラム・マップ・転調

命令範囲初期意味いま
@D n ※0, 1, 20（10パートは 1）ドラム許可。0 通常、1 と 2 はドラムマップ。XG では 1 も 2 も同じ。Lv2 の XG は 0 音色、1=127、48=Ex、64=SFX、126=SFX-K、127=Drum。捨てる。@DRUM 1 / 0
@W n0～30SC-55 マップ（88/88Pro）。Lv1 は 0=55、1=88。Lv2 は 0 既定、1=55、2=88、3=88Pro。Lv1 と Lv2 で意味が違う。捨てる
@K n52～7664キー。64 が無転調、65 が +1、63 が −1。曲の途中でも可。捨てる

@ GS / XG の効果

命令引数意味いま
@R n:m:k ※n 0～7、m/k 0～127GS リバーブ。n マクロ、m LEVEL、k TIME。XG では番号を変換。3 整数として残す
@C n:m:k ※同じGS コーラス。m LEVEL、k RATE。XG では番号を変換。捨てる
@＜ n ※0～127アタックレート。旧ヘルプは説明を省いています。コンパイルできない
@＞ n ※0～127リリースレート。同上。コンパイルできない
@S n ※0～127ソフト。同上。捨てる
@H n ※0～127ハード。同上。捨てる。頭の H n は別命令

音色の微調整

旧ヘルプの見出しは @ のあとに項目と値です。項目 n は 0～7、値 m は 14～114（64 が 0、−50～+50）。いまの @数字 はプログラム番号なので、この微調整としては残りません。

n項目
0ビブラートレート
1ビブラートデプス
2ビブラートディレイ
3TVF カットオフ
4TVF レゾナンス
5TVF/TVA アタック
6TVF/TVA ディケイ
7TVF/TVA リリース

ドラム音の微調整 @r

旧ヘルプは @r n:m:k です。m はキー番号で、O3C が 36。いまの Composer は @r を @R と同じ 3 整数命令にします。

nk の意味
0ピッチ。0～127、64 が 0。−64～+64 半音
1レベル。0～127
2パン。0 はランダム、1～64～127 が左～中央～右
3リバーブセンド。0～127
4コーラスセンド。0～127

@ エクスクルーシブと CC

一行に書きます。16進 2 桁。区切りはコンマか空白、無くても可。0～9 と A～F。末尾のチェックサムと F7 はコンパイラが付けます。データに FF は使いません（コンパイラが EOE に使うため）。

  • @(10,20,30,40,50,60,7F,1F) …… GS 固定。頭の F0 41 10 42 12 は自動。アドレスとデータだけ書く。※
  • @(M01:F0,41,10,45,12:10,00,00,35,35) …… モード付き。0=55（88Pro）、1=88、2=XG。複数可。@(M0: は 55 だけ、@(M02: は 55 と XG。頭とアドレスの境は :。チェックサムと F7 は自動。※
  • @(B01,30) または @(B 01,30) …… CC。Bn は自動で、番号と値を書く。例はモジュレーション 0x30。※

これらの @( は、いまの Composer では @ 命令として通りません。SysEx は @EX、任意 CC は @CC です。

$ 命令

頭は $。大文字。Composer はベロシティ、CC、GS/XG の SysEx として出します。$M は再生時の音源モードが一致したとき、そのパートの続きを止めます。$CG の TIME 欄は GS に番地が無いので、受け取るが出しません。命令の形でない $ だけ区切りとして読み飛ばします。

命令範囲意味
$( n1～99ベロシティを @N から n 下げる。0～127 の検査はしない。例 @N100 C $(20 C
$) n1～99n 上げる。例 @N100 C $)20 C
$M n0～3そのモードでは出さない。0=55（88Pro）、1=88、2=XG、3=GM（GM2、Win版から）。$M0$M1 は 55 と 88 を止める。
$L / $l—88Pro レガート on / off。音色名のうしろに : がある音。例 C $L DEFGAB $l
$I n0, 188Pro の EFX。0 off、1 on。
$(I n:m,…)n 0～6488Pro EFX。0 Thru、1～64 が番号。パラメータは若い番号から。省略は空欄（,,）。数が違うとエラー。実行後に $+ と $# が使える（CC16 と CC17）。
$+ n / $# n0～127EFX の + パラメータ / # パラメータ。初期 0。

$(I の書き方

  • $(I37) …… EFX 37（OD→Delay）。パラメータは初期値。
  • $(I37:50,,02,01,30,) …… Drive を 50、パンは省略、Amp は 2、ディレイタイムは 30。残りは省略。
  • $(I37:50,40,02,01,30,40,7f,40,40,40,7f) …… パラメータを全部書く。

GS / XG をまとめて書く

省略は ,,。GS 系は 10 進、XG 系は 16進 2 桁（$(I と同じ）。0 番は使えません。

命令中身
$RG(...)GS リバーブ。Macro, PRE-LPF, LEVEL, TIME, DELAY FEEDBACK, PREDELAY[88]
$CG(...)GS コーラス。Macro, PRE-LPF, LEVEL, TIME, FEEDBACK, DELAY, RATE, DEPTH, SEND Rev, SEND Del[88]
$VG(...)GS ディレイ（88 以上）。Macro, PRE-LPF, T.Center, T.R.Left, T.R.Right, L.Center, L.Left, L.Right, LEVEL, FEEDBACK, SEND Rev
$RX(...)XG リバーブ。番号と 13 パラメータ。準拠なら 1～8。MU80 の 9～12 も記載あり。
$CX(...)XG コーラス。番号と 10 パラメータ。準拠なら 1～8。
$VX(...)XG バリエーション。パラメータ数は種類による。準拠なら 1～38。MU80 の 39～44 も記載あり。

ピッチの数値

旧ヘルプは「1 半音が 341.333Hz、基準が 8192Hz」と書いています。単位の呼び方は Hz ですが、入れる値は @P の 0～16383 です。8192 が中央のド。（）は基準を C にした音名、数字は半音差です。

半音  +24   +12    +0    -12    -24
音    C     C      C     C      C
@P   16383 12287  8192  4095    0

隣の半音は約 341.33。例: +1 (C#) = 8533、 -1 (B) = 7850。
