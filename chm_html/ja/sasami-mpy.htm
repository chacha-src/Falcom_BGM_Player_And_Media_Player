SASAMI .mpy コマンド（全部）

kbsasami が .mpy を SMF に展開して鳴らすときのコマンドを全部載せます。64 トラックや二重ポートは .mpw2 の差分、VST バインドは .mpsmv の差分 です。

ファイルの形

  • マジック無し（先頭はトラックポインタ）。版バイト 0x80/0x81（例 0x33 0x75）。
  • 0x82＝二重 MIDI ポート、0x83＝wide（1 なら 64 トラック）。クラシック .mpy は 32 トラック・16bit ポインタ（ch0 はオフセット 0、ch32 以降は 0x100）。
  • 曲名は 0x160 から Shift-JIS 64×3（タイトル／作者／コメント）。
  • ストリームは 0x200 付近から。アドレスはファイルオフセット＋0x1000。
  • 命令は基本 3 バイト。cmd13/14/15 と 37、46、47 は 4 バイト。cmd36/40 は可変長。
  • ジャンプ（cmd10/24）のオペランドは 16bit 絶対（0x1xxx）。0xF0 でトラック終了。

マップ

再生時の GS/XG/55/88 などは kbsasami.midimode とプレイリスト「ささみ☆ﾐ 音源モード」です。同じ番号の命令でも、88map では b1、55map では b2 を使うものがあります（cmd2/5/7/12）。

Composer が .mpy を選ぶとき

VST バインド無し、ネイティブ ｛: 無し、@CC 類無し、ループ入れ子 1 段まで。譜面 Save As でも同じ規則です。

ヒント

kbsasami は cmd41/46/47 も .mpy で解釈できます。Composer の @CC 類は互換のため .mpsmv＋cmd41 にします。@SVIB はどの形式でも細分化で、cmd46/47 は出しません。
