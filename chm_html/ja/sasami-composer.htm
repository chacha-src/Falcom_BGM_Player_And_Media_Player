SASAMI Composer（曲を作る）

メディアプレイヤーの「ツール」から開く SASAMI Composer で、ささみ☆ミ形式の曲データを新規作成できます。旧 Win版 sasamim の役割をここに集約しています。

開き方

メディアプレイヤー画面で ツール を押し、サブメニュー SASAMI から次を選びます。

  • テキスト … MICP／MML3 両対応の色つき編集とコンパイル
  • MIDI譜面 … 五線スコア（左トラック／Strip／音符パレット）。VST2/3 音色
  • FM譜面 … 同じ五線シェル（FM10＋Misao16）。ダブルクリックで音色エディタ

テキスト

簡易方言（#1・小文字 t120・cdefgab）に加え、旧 MICP／SASAMIM 実曲文法も同じコンパイルで読めます。[port:ch]・大文字 T テンポ・@prog:bank・P/Q/O/L/V・付点・^ タイなどが使えます。コメントは ; または // です。

@SVIB / @STREM / @SPAN / @SPORTA は 内部で ｛: :｝ 相当に展開し、クラシックなピッチ・音量・パン命令になります。そのため MPY / MPW2 / FPY のまま旧プレイヤーでも再生できます（MPW3/FPY2 必須ではありません）。

VST3 曲にするときは @VST"プラグインのパス" と @PROG・@BANK を書き、保存形式は MPW3 になります。FM は先頭に OPNA（または OPN）を置き、コンパイルすると FPY になります。

MIDI五線スコア

複数トラックの五線に符頭を置きます。上ツールで鉛筆／消しゴム／選択、浮遊「音符」パレットで音価、下の Expression Strip で強弱を編集します。トラック見出しや五線をダブルクリックすると、そのパートの VST2/VST3 エディタが開きます。VST を使わない曲は MPW2／MPY、VST を紐づけた曲は MPW3 で保存します。

FM五線スコアと音色

FM1–10 と Misao1–16 を同じ五線シェルで編集します。ダブルクリックで音色エディタを開き、発音を確認してから確定します。Strip 既定は Volume です。音色番号は曲内で自動採番されます。

再生確認と音声書き出し

各ウィンドウの「再生確認」は一時ファイルへ書き出してプレイリストへ追加します。「書き出し」から WAV／MP3／FLAC 変換ダイアログを開けます。

ヒント

3つのウィンドウは別々に開けます。同じ曲を同時に複数窓で編集するときは保存先に注意してください。
