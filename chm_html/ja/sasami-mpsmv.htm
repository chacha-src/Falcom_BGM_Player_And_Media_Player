SASAMI .mpsmv — .mpw2 からの差分

.mpsmv の MIDI 本体は .mpw2（つまり .mpy の命令）です。ファイル末尾に MPW3 トレイラが付き、ホストが HALion などの VST をパートへ載せます。KPI 内 fmmidi ではなく、本体の .mid を VST で鳴らす と同じ経路です。

トレイラ MPW3

MIDI 本体の直後にマジック MPW3、続けて u32 版（1 または 2）。そのあと 32 パート分です。

欄大きさ内容
パス520 バイトUTF-16 相当の VST パス。@VST"…" / 譜面 Tone。
prog / msb / lsb / forceCh各 4 バイト@PROG @BANK。forceCh は実 MIDI ch 固定。
compLen + blob4+可変完全状態。@VSTSTATEB64（続きは @VSTSTATEB64+）。
ctrlLen + blob4+可変パラメータのみ。@VSTCTRLB64。

版が 2 以上でマクロがあるとき、トレイラの後ろに MACR ＋個数、名前 64 wchar、本文長、本文。@MACRO name ｛…｝ / @CALL name。

インサート FX

@VSTFX slot "path" と @VSTFXSTATEB64 slot。譜面の Insert FX。本体はパートの VST チェーンに載ります（トレイラの拡張領域）。

本文側で Composer が変える命令

Composer.mpy/.mpw2.mpsmv
@CC n,v形式を .mpsmv にするcmd41 のまま
@MOD @SOFT @SOST @REV @CHO形式を .mpsmv にするcmd41（CC1/67/66/91/93）。クラシック cmd6/17/18 には落とさない
@SVIB @STREM @SPANピッチ等に細分化同じ細分化（cmd46 は出さない）
@SPORTA細分化同じ細分化（cmd47 は出さない）
｛:n … ｝:テキスト展開cmd23/24 のネイティブ（非展開）
@METER / @TS形式を .mpsmv譜面グリッド用（ストリーム命令ではない）
@VST 類形式が変わるトレイラへ
@MACRO / @CALL形式が変わるMACR フッタ。呼び出しはコンパイル時展開可

Composer が .mpsmv を選ぶとき

  • @VST、@VSTSTATEB64、@VSTCTRLB64、@VSTFX がある。
  • @METER / @TS。
  • @MACRO / @CALL。
  • @CC / @MOD / @SOFT / @SOST / @REV / @CHO（および CHORUS/REVERB 別名）。
  • テキストにネイティブ ｛: がある。
  • 譜面 Tone に VST パスがある。

再生経路

本体はトレイラを読んで各パートの VST を開き、SMF 相当のノートをそのパートへ送ります。MIDI マッパーの GM ピアノにはしません。kbsasami.vst と raira=1 の入れ替えは、プレイリストの midPlayPrefer（KPI の fmmidi かホスト VST か）用です。

テキスト UI の B64

長い @VSTSTATEB64 は「B64折畳」で省略表示できます。保存・コンパイル時はフル行に戻します。

ヒント

命令番号の辞書は .mpy 全部、入れ子と 64ch は .mpw2、このページはトレイラと「展開しない」系統だけです。

注意

プレビュー用の一時ファイル名は ogg_sasami_score.mpsmv などになります。プレイリストに残したくなければ削除してください。
