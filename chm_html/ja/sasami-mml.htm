SASAMI MML（MICP 標準）

Win版「ささみ☆ミ」のヘルプ SASAMIM.HLP（2000年）にある MICP の書き方です。音階・パート・標準命令・ドラム・短いサンプルをここにまとめています。@ と $、ピッチの数値表は 拡張命令 です。テキストからどのファイルになるかは SASAMI Composer を見てください。

音階と音長

オクターブは 1 が一番低く、8 が一番高いです。初期値は 4。音名のあとに長さを書くと、その音だけ L を上書きします。C4 は L4C と同じです。

旧ヘルプの E+（F-）はファ、という注記でした。いまの Composer は + / # を半音上、- を半音下として、MIDI では o4 の C がノート 60 です。

音符の直後の & は、旧ヘルプではゲートを最大にします。次の音が同じ高さならタイです。例: q32 のとき C4& は q64C4q32、C4&C4 は q64C4^8R8q32。いまの Composer では & も ^ も、直前の音符の長さを足します。

パート

[パート:ワーク] でチャンネルを始めます。ワークは省略でき、空いている番号を使います。ワークは 1～63 で、同じ番号は重ねません。

  • 1～16 …… MIDI の A ポート。
  • 17～32 …… MIDI の B ポート。旧ヘルプでは 32ch モード以外は無効。
  • 同じパートに音を重ねるときは、ワークを変えて同じパート番号を並べます。
[2:1] C4
[2:2] E4
[2:3] G4

[2] C4
[2] E4
[2] G4

上はどちらもドミソの和音です。いまの Composer は #n（1 始まり）も読めます。コメントは ; から行末、または // です。

標準命令

旧ヘルプは半角大文字指定です。範囲と初期値はその記載です。右端は、いまのテキスト Composer がイベントにするかどうかです。

命令範囲初期意味いま
T n40～3000—テンポ。大きいほど速い。相対変化は無いので、変えるときは書き直す。出す（t も可）
O n1～84オクターブ。端の音は鳴らないことがある。出す（o も可。0 も通る）
L n1～1924音長。192 で割れる値。4分の3連は 4×3 で L12。出す
! n1～255—音長の数値版。4分音符が 48。文字だけ捨てる
R n1～192L休符。省略時は L。3連も L と同じ。大文字 R は休符。小文字 r は待ち
^ n1～192Lタイ。n のあいだ前の状態を保つ。直前の音符を伸ばす
Q / J——Q から J までを永久ループ。出す
＞——オクターブを 1 上げる。出す
＜——オクターブを 1 下げる。出す
P0～12764パン。0 左、64 中央、127 右。パートごと。出す。P64:85 の副値は捨てる
|: n … :|2～2502メモリ節約ループ。回数分繰り返す。ピッチの相対変化には向かない。出す
｛: n … ｝:2～2502展開ループ。回数だけデータが増える。相対ピッチはこちら。クラシックは展開。新形式は命令のまま
( / )——ペダル on / off。例 (L16CDE8^2.)。出す（CC64。@PEDON / @PEDOFF と同じ）
q n1～6464ゲート。音符の n/64 だけ鳴らして残りは休み。出す（100 まで読む）
I n0～127—GS リバーブセンド。命令として残す
K n0～127—GS コーラスセンド。読み飛ばす
W / M——エクスプレッションを 1 上げる / 下げる。読み飛ばす
_0——次行の半角 64 文字をタイトル。タイトルは TIT"…"
_1——次行の引用符内（行頭、半角 30 文字）を表示文字。16 文字を超えるとスクロール。読み飛ばす
注意

旧ヘルプは |: と ｛: の入れ子を禁止しています。いまの Composer は入れ子できます。1 段なら .mpy / .fpy、2 段以上は .mpw2 / .fpy2 です。＞ が上がって ＜ が下がるのは旧ヘルプと同じです。PMD の向きとは逆です。

ドラム（小文字）

旧ヘルプのドラム文字です。長さは L と同じで、省略すると L です。ノート番号が分かれば普通の音名でも書けます。旧ヘルプでは s と O3C が同じ、としています。

文字楽器いま
hハイハット（クローズ）出す（ノート 42）
sスネア出す（38）
bバスドラム出す（36）
oオープンハイハット専用文字は無い（o はオクターブ）
cシンバル専用文字は無い（c はド）
lロータム専用文字は無い（l は音長）
mミドルタム読み飛ばす
fハイタム専用文字は無い（f はファ）
r（旧表には無い）ドラムパートではライド 51

ドラムにする指定は、旧ヘルプでは拡張の @D です。いまは @DRUM 1、または MIDI 10 / 26 が既定のドラムです。詳しくは拡張命令のページ。
