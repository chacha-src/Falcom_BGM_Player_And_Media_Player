再生詳細

メディアプレイヤーの「詳細」ボタン、またはプレイリストの右クリックから開く画面です。再生のこまかい設定と、その曲のループやキュー、タグが1か所に集まっています。多くの項目はすぐに音へ反映されます。

再生詳細

再生とレベル

ギャップレス
連続再生のときに、曲間の無音を詰めて切れ目なくつなぎます。ライブ盤やつながっているアルバムで効きます。
ReplayGain
Off / Track / Album から選びます。曲やアルバムごとの音量差を自動でそろえます。目標のラウドネスも指定できます。
Mid/Side 幅
左右の広がりです。100が通常、下げると狭く、上げると広がります。0にすると中央寄せになります。
モノ互換チェック
サイド成分を抑えて、モノラルで聴いたときに音が消えないかを確かめられます。
位相相関メーター
左右の相関（φ）を表示します。メディアプレイヤーのバナー右のメーターにも反映されます。
ボーカル Mid
0がキャンセル寄り、100が中立、200が強調です。右クリックでプリセットも選べます。詳しくは 音を整えるツール へ。
書き出しリミッター
書き出すときの音量の上限を決めて、割れを防ぎます。天井の値（例：-1.0 dB）と True Peak 制限も選べます。

ループとキュー

  • 画面の波形をクリックするとイン点、Shift+クリックでアウト点を置けます。緑がイン、赤がアウトです。
  • ループのイン／アウト／境界のフェード（ミリ秒）を入れて「適用」すると、次のループから効きます。
  • 「現在位置をイン／アウトに」のボタンで、いま鳴っている場所をそのまま使えます。
  • キューは現在位置に追加・削除・ジャンプできます。曲ごとの目印として残ります。キュー、A-B、練習テンポ もご覧ください。

タグ

タイトル、アーティスト、アルバム、年、トラック、ジャンル、コメントを見て、そのままファイルへ書き込めます。コメント欄では LOOPSTART / LOOPEND / LOOPLENGTH も書き込めるので、ループ位置をファイル自体に残せます。

書き込みに対応している形式は MP3 / FLAC / WAV / M4A / Ogg Vorbis です。たくさんの曲をまとめて直したいときは タグを編集する が向いています。

閉じるとき

「適用」でループなどを確定します。「OK」または「閉じる」でウィンドウを閉じますが、すでに反映された値はそのまま残ります。

ヒント

この画面の「？」ボタンを押すと、項目の並びを図で見られます。各画面の「？」操作ガイド をご覧ください。

注意

暗号化されたFLACと、Opusへのタグ書き込みには対応していません。
