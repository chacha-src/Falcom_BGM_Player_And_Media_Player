タグを編集する

プレイリストの右クリック「タグ編集」から開きます。曲の名前がそろっていないコレクションを整えるのに向いています。複数の曲を選べば、まとめて書き換えることもできます。

編集できる項目

  • タイトル / アーティスト / アルバム
  • 年 / トラック番号 / ジャンル
  • コメント
  • ジャケット（アルバムの画像）

1曲を直す

  1. プレイリストで曲を右クリックし、「タグ編集」を選びます。
  2. 直したい欄を書き換えます。
  3. ジャケットを変えるなら、画像を選び直します。
  4. 書き込みを実行すると、ファイル自体に保存されます。

まとめて直す

複数の曲を選んで開くと「まとめて編集」になります。

  • 入力した欄だけが、選んだすべての曲へ適用されます。
  • 空欄のままにした項目は変わりません。アルバム名だけそろえたいときは、アルバムの欄だけ書けば安全です。
  • 同じアルバムの曲をまとめて選び、アルバム名とジャケットをそろえるのが定番の使い方です。

書き込みに対応する形式

MP3 / FLAC / WAV / M4A / Ogg Vorbis に書き込めます。

注意

暗号化されたFLACと、Opusへの書き込みには対応していません。また、書き込みはファイルを実際に変更します。大量にまとめて実行する前に、大切なファイルはバックアップしておくと安心です。

自動で調べて入れる

附属ツールいろいろ の「MusicBrainz 自動タグ」を使うと、曲名やアーティスト名から候補を探してタグへ反映できます。音の指紋による照合はしないので、もとの曲名がまったく分からない曲では見つからないこともあります。

タグを整えると何がよくなるか

  • 歌詞を表示する のネット取得が当たりやすくなります。
  • スマートプレイリストと書庫ツリー の条件がきちんと効きます。
  • 音声書き出し（WAV / mp3 / FLAC） で「タグとジャケットをコピー」したときに、できたファイルもきれいになります。
  • スマホやPCから操作する や配信の画面表示も読みやすくなります。
ヒント

タグではなく「このソフトの中での表示だけ」を直したいときは、ファイル情報を見る・直す の表示名を変えてください。ファイルには手を付けずに済みます。
