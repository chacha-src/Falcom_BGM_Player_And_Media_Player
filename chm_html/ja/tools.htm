附属ツールいろいろ

メディアプレイヤーのツール右クリック、または各ウィンドウの右クリックから開ける便利機能です。数が多いので、ここでは「何をするものか」を一覧にしています。気になるものから試してみてください。

歌詞・譜面まわり

歌詞ウィンドウ
常時最前面の歌詞表示です。透明度・行数・フォント・位置を覚えます。LRC のずれ補正（±10 / ±50 / ±100ms）と保存もできます。歌詞を表示する をご覧ください。
ピアノロール拡張
再生中の MIDI / MusicXML 録り（実験的）、コード進行パネル、パソコンで鳴っている音の譜面化ができます。ピアノロールで音を見る をご覧ください。
スペクトロジャケット
波形・周波数アナライザー の表示を画像として保存します。

音を整える・書き出す

A-B／キュー素材パック
A-B やキューの区間を連番のファイルとして書き出します。キュー、A-B、練習テンポ と組み合わせて使います。
音量正規化バッチ
選んだ曲を、目標のラウドネスに寄せて書き出します（リミッター併用）。
ボーカルキャンセル／強調
真ん中の成分を弱めたり強めたりします。音を整えるツール から操作します。
M/S プリセット
相関のまわりから、狭める／広げる／モノをワンクリックで当てます。
キー→EQ提案
検出した調（キー）から、合いそうな イコライザーと環境モデル のプリセットをすすめます。
動画の音声抽出／差し替え
選んだ動画から WAV を取り出す、または外部の WAV で音声を差し替えて MP4 にします。動画を再生する をご覧ください。

タグ・情報

MusicBrainz 自動タグ
曲名・アーティストなどから候補を引いてタグへ反映します（指紋照合はしません）。タグを編集する をご覧ください。
nowplaying.txt
いま鳴っている曲名を、実行ファイルと同じ場所へ書き出します。配信の画面表示に使えます。ライブ配信する をご覧ください。

演奏・DJ

BPM計測
BPMを測る をご覧ください。
キー確定／Camelot相性
解析した調を曲ごとに覚えます。いまのプレイリストから、隣り合う調（相性のよい調）の曲を次曲候補として並べます。
DJパッド
DJパッドで遊ぶ をご覧ください。
MIDIキーボード操作
MIDIキーボードで操作する をご覧ください。
トランジション・プリセット
EQスイープ、フィルタ、クロスフェード秒の組み合わせを「次曲向け」に当てます。時系列の自動化そのものは コマンドロールで並べる 側です。

録る・配る

ライブセット録画
画面を録画する と 再生している音を録音する をまとめて開きます。
ゲーム録画プリセット
上と似ていますが、ゲーム向けの設定でまとめて開きます（ネット配信ではありません）。
出力ミラー
もう一台のスピーカーへ同時に出す をご覧ください。
ローカルリモート
スマホやPCから操作する をご覧ください。
スクリーンセーバー風ビジュアライザ
フルスクリーンで音に合わせた表示をします。ESC で解除できます。

暮らしに合わせる

アラーム
指定した時刻に再生を始めます。スリープタイマーとアラーム をご覧ください。
フォーカスモード
余計な表示を減らして集中できるようにします。
危険操作確認
消してしまうような操作の前に、確認を出すようにします。
レイアウト1〜3
窓の配置を3種類まで覚えて呼び出せます。
週次サマリ / 練習ログ
どれくらい聴いたか・練習したかを振り返れます。再生履歴を見る と合わせてどうぞ。
リスト削除の1段Undo
右クリックの「削除を元に戻す」で、直前の削除だけ戻せます。全部の履歴を戻すものではありません。
