対応データシート

どの作品のBGMがゲーム中と同じループで聴けるか、そして CEmu（CPUエミュレーション）以外の音をどのエンジンが読んでいるかを、1枚にまとめたページです。昔マシンの zip はここには含めず、PC-98、PC-88、X68000、X1、MSX、FM-7、PC/AT、アーケード に分けてあります。

本体と、横にいるプロセス

プレイヤー本体は x64 です。以前の本体は x86（32bit）でした。反対に、ビット数が違うプラグインを預かる側は x86 の ogghost32.exe になりました。以前その役目だったのは x64 の KpiHost64.exe です。

  • 64bit の VST や KPI は、本体が直接読みます。
  • 32bit の VST や KPI、Winamp / XMPlay / AIMP の入力プラグインは、ogghost32.exe を起こして名前付きパイプで開きます。実行ファイルと同じ場所に置いてください。
  • 鍵盤で鳴らす VST のノートと音声はパイプを通さず、共有メモリで渡します。開く・閉じるなどの手続きだけがパイプです。

一覧に付く &lt;x86&gt; と &lt;x64&gt; は、そのプラグインのビット数です。詳しい置き方は KPIプラグインで対応形式をふやす と VSTホストで音源を鳴らす をご覧ください。

内蔵の再生エンジン（CEmu を除く）

ふだんのファイルは、CPU をまねる CEmu ではなく、次のエンジンが読みます。珍しい形式だけ KPIプラグインで対応形式をふやす へ回します。
