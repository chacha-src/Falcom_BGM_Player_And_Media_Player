ゲームフォルダの設定

「フォルダ設定」では、ゲームがどこにインストールされているかをソフトに教えます。既定では各ゲームの標準インストール先が入っているので、ふつうにインストールしてあればそのまま見つかります。Steam版を別ドライブに入れた場合などは、ここを直してください。

設定のしかた

  1. ファルコムBGM画面から「フォルダ設定」を開きます。
  2. 設定したいゲームの行を探します。
  3. 参照ボタンでゲームのフォルダを選びます。ふつうはゲームの実行ファイル（exe）がある場所を指定します。
  4. 設定を保存して閉じ、ファルコムBGM画面 でそのゲームを選び直します。

うまく見つからないときのヒント

  • Steam版は steamapps\common\ゲーム名 の中にあります。
  • BGMのデータが入っているサブフォルダ（bgm、voice、data など）ではなく、その上のゲーム本体のフォルダを指定するのが基本です。
  • パスに日本語が含まれていても問題ありません。
  • 外付けドライブに置いている場合は、ドライブレターが変わると見つからなくなります。そのときはもう一度指定し直してください。

WAVをコピーして使うタイトル

ブランディッシュ4 と、ガガーブトリロジー三部作（白き魔女／朱紅い雫／海の檻歌）は、CD や DVD の中の WAV ファイルをハードディスクへコピーしてから使います。

  1. ディスクの中の WAVE、WAVEDV、WAVEDVD といったフォルダを、ハードディスクの好きな場所へコピーします。フォルダ名はゲームによって違います。
  2. フォルダ設定で、そのコピー先を指定します。
ヒント

設定し終えたら、気に入った曲を プレイリスト へドラッグ＆ドロップしておくと、次からはメディアプレイヤー画面でも手早く呼び出せます。曲ごとの音量やイコライザーも覚えてくれます。

注意

フォルダを指定しても曲が鳴らないときは、そのゲームがまだ対応していない可能性もあります。対応タイトルの一覧は 対応形式と対応タイトル で確認できます。
