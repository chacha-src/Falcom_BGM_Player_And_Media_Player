連続再生クロスフェード

連続再生がONのとき、曲の終わりで次の曲を指定した秒数だけ重ねて、自然に切り替えられます。パーティーで流しっぱなしにしたいときや、曲間の無音が気になるときに効きます。

使いかた

  1. 再生と停止、音量 の「連続再生」をONにします。これが前提です。
  2. クロスフェードのチェックを入れます。メイン画面とメディアプレイヤー画面のどちらからでも設定できます。
  3. 重ねる秒数を入れます。小数も使えます。既定は 5.00 秒です。
  4. そのまま聴いていると、曲の終わりで次の曲が重なってきます。

曲のつなぎかた

  • 曲の終わりが近づくと、次の曲を裏でそっと開きます。
  • 指定した秒数のあいだ、いまの曲と次の曲をなめらかに混ぜます。どちらも小さくなりすぎないので、音量が落ち込みません。
  • 混ぜ終わったら、次の曲が本編の再生になります。このときプレイリストの♪、ジャケット、時間やタグの欄も更新されます。
  • チャンネル印（緑の MONO / LR / 2.1…）も、次の曲を裏で開いた時点で確定してリストへ付きます。VST MIDI や m4a のようにヘッダだけでは分からない形式も、通常再生と同じく印が出ます。
  • 動画の行や再生できない行はスキップして、次の音声曲へ進みます。

つないだ音をそのまま録りたいとき

WAVへ保存する と一緒に使うと「チェック用」モードになります。

  • 最初に流した曲名のWAVファイルへ、そのまま追記し続けます。
  • 出力はきれいめな WAV に固定されます。聞こえている音をそのまま残したものです。
  • 停止すると、そのファイルが確定します。
ヒント

曲どうしのつながりを良くしたいときは、BPMを測る でテンポを測ってからクロスフェード秒に反映させると、拍が合ったまま渡りやすくなります。附属ツールいろいろ の「キー確定／Camelot相性」で調の相性がよい曲を次に置くのも効果的です。

注意

クロスフェード中は2曲ぶんの音を作るので、古いパソコンでは少し重くなることがあります。音が途切れるときは、レンダリング設定 でバッファを大きくしてみてください。
