チューナー道場

楽器のチューニングと、テンポに合わせた練習をひとつにまとめた画面です。マイクへ単音を入れると音名とずれ（セント）が出て、クリック（メトロノーム）を鳴らしながら練習できます。

チューナーとして使う

  1. マイク で使うマイクを選びます。見つからないときは「再検出」を押します。
  2. 楽器の音をひとつだけ鳴らします。
  3. 画面に音名と、何セントずれているかが出ます。
  4. 針が真ん中に来るように、楽器を合わせます。

針の表示は左右 ±100 セントの範囲です。真ん中が合っている状態です。

基準の高さ（A4）

A4 のコンボで基準の高さを変えられます。合わせる相手（ピアノやオーケストラ）に合わせて選んでください。

メトロノームとして使う

  1. BPM でテンポを選びます。
  2. 拍 で拍子を選びます。
  3. クリック出 で音を出すデバイスを選びます。
  4. 「クリック」ボタンを押すと鳴り始めます。

先頭の拍だけ高い音で鳴るので、何拍目かが耳で分かります。静かにしたいときは「ミュート」にチェックを入れてください。

フレーズA-B

「フレーズA-B」ボタンを押すと、いま再生している位置の前後に練習用の A-B 範囲をその場で作ります。「この4小節だけくり返して弾く」という練習がすぐ始められます。

この機能を使うには、メディアプレイヤーが必要です。曲を再生した状態で押してください。キュー、A-B、練習テンポ も合わせてご覧ください。

練習に効く組み合わせ

  • テンポとピッチを変える でゆっくり流してから合わせる。
  • BPMを測る で曲のテンポを測って、その値をクリックに入れる。
  • ピアノロールで音を見る でコードを目で確かめる。
  • 附属ツールいろいろ の練習ログで、どれだけやったかを残す。
注意

この機能は趣味用途の単音向けです。和音を鳴らしたり、周りがうるさい場所では正確に測れません。静かなところで、ひとつの音だけを鳴らして使ってください。

あわせて読みたい
  • キュー、A-B、練習テンポ
  • テンポとピッチを変える
  • BPMを測る
  • ピアノロールで音を見る
  • 附属ツールいろいろ
