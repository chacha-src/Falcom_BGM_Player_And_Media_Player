BPMを測る

BPM は1分あたりの拍の数、つまり曲の速さです。測ったBPMは、シークバーの拍グリッドや、クロスフェードの秒数を決めるのに使えます。

BPM検出

測る手順

  1. メディアプレイヤー下段の「BPM」ボタンを押します。
  2. 曲を再生します（またはパソコンで鳴っている音を使います）。
  3. 計測のチェックをONにすると、聴きながら測り始めます。
  4. しばらく再生して、数字が落ち着いたらチェックをOFFにします。
  5. OFFにしたときの値が、拍グリッドや書き出しクロスフェード秒に反映されます。

測った値の使いみち

拍グリッド
シークバーに拍の縦線が引かれます。「4小節あと」といった感覚で位置を決められるようになります。シークバーの読み方 をご覧ください。
拍の位置合わせ
線の位置が実際の拍とずれているときは、シークバー上を Alt を押しながらドラッグしてずらせます。この調整はBPMと一緒に曲ごとに覚えます。
クロスフェードの秒数
テンポが分かると、拍の切れ目で自然につながる秒数が決めやすくなります。連続再生クロスフェード と 音声書き出し（WAV / mp3 / FLAC） の両方で活きます。
±拍の操作
DJパッドで遊ぶ の「±拍」が正しく効くようになります。

メトロノームとして使いたいとき

音を鳴らして合わせて練習したいなら、チューナー道場 のクリック（メトロノーム）が向いています。BPMと拍子を選べて、先頭の拍だけ高い音で鳴ります。

覚えた値はどこへ行くのか

BPM、拍のずれ、そしてキーは SongParams.dat に曲ごとに保存され、次に再生したときに戻ってきます。一度きちんと測っておけば、あとはずっと使えます。

ヒント

パソコンで鳴っているほかのソフトの音でも測れます。動画サイトの曲のテンポを知りたいときにも使えます。

注意

テンポが途中で変わる曲や、拍がはっきりしない曲ではうまく測れないことがあります。その場合は、拍がはっきりしている部分だけを再生してみてください。
