はじめて起動したとき

インストール後にはじめて起動すると、いくつか質問されます。どれも後から変えられるものなので、気軽に選んでかまいません。このページでは最初の数分でやっておくと快適になることをまとめます。

起動後に見えるメイン画面の例

1. 起動する画面を選ぶ

「起動モードの選択」という小さなダイアログが出て、ファルコムbgm特化型画面 と メディアプレイヤー画面 のどちらで始めるかを聞かれます。

  • ゲームのBGMをループ付きで聴きたいなら ファルコムbgm特化型画面。
  • ふだんの音楽・動画をプレイリストで聴きたいなら メディアプレイヤー画面。

下の「次回も起動時に確認する」のチェックを外すと、次回からは選んだ画面でそのまま起動します。気が変わったら ふたつの画面モード の手順でいつでも切り替えられます。

2. 表示言語を選ぶ

レンダリング設定 の中に言語の項目があります。日本語・英語・フランス語・イタリア語・スペイン語・韓国語・中国語・アラビア語・ロシア語・ドイツ語・ポルトガル語・オランダ語・ポーランド語・トルコ語の14言語から選べます。

3. 音の出口を確かめる

音が出ないときは、たいてい再生する端末（スピーカーやヘッドホン）の選択がずれています。レンダリング設定 で再生デバイスを選び直してください。Windowsのミキサーでこのアプリだけミュートになっている場合は、起動時に警告が出ます。

4. ゲームBGMを聴くなら、フォルダを教える

ファルコム作品のBGMは、ゲームがインストールされている場所を読み込んで再生します。既定では標準のインストール先が入っているので、そのままで見つかることも多いです。見つからないときは ゲームフォルダの設定 で指定してください。

5. 手持ちの曲を聴くなら、ドラッグ＆ドロップ

  1. メディアプレイヤー画面を開きます。
  2. エクスプローラから音楽ファイルやフォルダを、プレイリストの上へドラッグ＆ドロップします。
  3. 曲をダブルクリックすると再生が始まります。
ヒント

よく使うファイル形式をこのソフトに関連付けておくと、エクスプローラでダブルクリックするだけで再生できます。レンダリング設定 の「ファイル関連付け」で、音声・動画・プレイリストをまとめて設定できます。

注意

avi などの動画がうまく再生できないときは、コーデックパック（K-Lite Codec Pack など）が必要です。詳しくは 動画を再生する をご覧ください。
