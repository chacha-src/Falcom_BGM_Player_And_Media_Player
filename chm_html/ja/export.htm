音声書き出し（WAV / mp3 / FLAC）

プレイリストの右クリック「音声書き出し」から開きます。タブで WAV / mp3 / FLAC を切り替えられます。いったんPCM（WAVの経路）へ作ってから、必要なら圧縮するしくみなので、どの形式でも同じオプションが使えます。

まずは1曲を書き出す

  1. プレイリストで曲を選び、右クリックから「音声書き出し」を開きます。
  2. 上のタブで形式（WAV / mp3 / FLAC）を選びます。
  3. ループ回数やフェードアウトを決めます。
  4. 保存先を指定して実行します。

長さを整えるオプション

ループ回数
ゲームBGMのようにループがある曲で、何回くり返してから終わるかを決めます。
フェードアウト
終わりを少しずつ小さくして消します。ループを途中で切っても不自然になりません。
先頭無音を揃える
曲の頭にある無音の長さをそろえます。長すぎる無音はカットし、短いときは無音を足して指定の秒数にします。並べて聴いたときの間が気持ちよくなります。
サンプリング
ソースのままか、44.1 / 48 / 88.2 / 96 / 192 kHz などを選べます。
長さ（秒）
KPIプラグインで対応形式をふやす で鳴らしている曲など、長さが分からない音源で使います。

タグとジャケット

  • 「タグとジャケットをコピー」で、もとの曲の情報を引き継げます。
  • タイトル・アーティスト・アルバム・ジャケットを、ここで別に指定することもできます。
  • 書き出す前にタグを整えておきたいときは タグを編集する をご覧ください。

演奏の動きを焼き込む

「プロンプト実行を適用」にチェックを入れると、演奏プロンプトで曲を動かす で書いた動きが書き出すPCMにそのまま反映されます。テンポやエフェクトが時間で動く音を、そのままファイルにできます。

クロスフェードで1本にまとめる

複数の曲を選んでいるときに使えます。曲を順につなげて1つのファイルにし、曲間を指定した秒数で等パワーに交差させます。右クリックの「クロスフェード書き出し」からも起動できます。

聴いているときだけつなぎたい場合は、ファイルを作らない 連続再生クロスフェード のほうが手軽です。

ミックスで重ねる

こちらも複数選択時のオプションです。同時に重ねる曲の数と、曲ごとの音量の割合（%）を指定して、1本のファイルにまとめます。クロスフェードと一緒に使うと、終わった枠へ次の曲が指定秒で入ってくるので、途切れずに続きます。

ヒント

書き出す音の上限を決めておくと、割れを防げます。音を整えるツール の書き出しリミッターと True Peak 制限をご覧ください。たくさんの曲の音量をそろえたいときは、附属ツールいろいろ の「音量正規化バッチ」が便利です。

注意

WAVで2GBを超える場合は RF64 形式になります。長時間の書き出しでもファイルが壊れません。
