.mid を VST 音源で鳴らす

プレイリストに入れた .mid（や .midi / .kar / .rmi）を、SOUND Canvas VA や S-YXG50 のような VST 音源で鳴らせます。リアルタイムに鍵盤を弾く VSTホストで音源を鳴らす とは別で、「曲ファイルを VST で演奏する」ための設定です。

VSTホストでのMIDI入力とパート

準備（レンダリング設定）

  1. レンダリング設定 を開きます。
  2. 「MIDI再生」で VST優先 を選びます（KPI優先のままでは VST 側になりません）。
  3. 「GS VST」に、GS 用の音源（SC-VA など）のファイルやフォルダを指定します。
  4. 「XG VST」に、XG 用の音源（S-YXG50 など）を指定します。
  5. 必要なら「再」でプラグインを探し直します。「VSTプラグインを検索しています…」という待ち画面が出ることがあります。

GS と XG のどちらが使われるか

  • 曲の中に XG System On（XGリセット）があれば → XG VST
  • それが無ければ → GS VST
  • 片方だけ指定してあるときは、その片方で両方をまかないます。
  • 両方とも空のときは、Windows の MIDI マッパー（または「MIDI出力」で選んだ端末）へ落ちます。

再生してみる

  1. .mid ファイルをプレイリストへ入れます。
  2. ダブルクリック（または再生）します。
  3. バナーに file:mid VST (32) や file:mid VST (64) のように出れば、VST 経由で鳴っています。VST が無いときは file:mid MIDI Mapper になります。
  4. 再生（または 連続再生クロスフェード の先読み）が始まると、プレイリストの印に緑の LR（など）が付きます。MIDI はヘッダだけではチャンネルが分からないため、開いたあとに確定します。

演奏の様子を見る

鳴らしている最中に MIDIモニタ を開くと、32パートの音色・音量・効果がリアルタイムで見られます。ピアノロールで音を見る と並べると便利です。

64bit の音源について

本体は 32bit なので、64bit の VST（SC-VA x64 など）は KpiHost64.exe を経由します。「x64 VSTホストを開けませんでした。KpiHost64.exe を確認してください。」と出たときは、実行ファイルと同じ場所に KpiHost64.exe があるかを確かめてください。KPIプラグインで対応形式をふやす と同じしくみです。

VSTホストとのちがい

目的プレイリストの SMF を鳴らす鍵盤からリアルタイムに鳴らす
開き方レンダリング設定の GS/XG VST下段の「VST」ボタン

ヒント

プロジェクトフォルダに .mid が無いときは、「MIDIが見つかりません。同フォルダに .mid をエクスポートしてください。」と出ることがあります。

注意

「VST MIDIを開けませんでした。」と出るときは、指定した DLL のパス、32/64bit の食い違い、KpiHost64.exe の有無を順に確かめてください。
