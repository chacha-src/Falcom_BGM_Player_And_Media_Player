WRDを見る

WRD は、PC-98 の MIMPI や TMIDI に付いていた歌詞・画面のスクリプトです。MIDI の演奏位置（小節や @WAIT）に合わせて、文字と MAG 画像を出します。音そのものは FM/MIDIモニタ や .mid を VST 音源で鳴らす の側です。

開く

  • メディアプレイヤーのバナーを右クリック → 「ウィンドウ」から WRD。
  • コマンドパレットから「WRD」。
  • 再生中の曲に WRD が付いていると、そのスクリプトを読みます。

画面に出るもの

スクリプトが読めると、歌詞と MAG 画像が演奏位置に追従します。付いていない曲では「WRDはありません」と出ます。普通の mp3 には WRD は入りません。

右クリック

常に手前
ほかの窓の上に重ねて置けます。
再読み込み
いまの WRD を読み直します。
MIDIモニタを開く
同じ曲の FM/MIDIモニタ を開きます。
ヒント

PC-98 の MIDI まとめを PC-98 で鳴らしているとき、歌詞スクリプトが同梱されていればこの画面と組み合わせられます。

注意

WRD の時刻は SMF のテンポ（4分音符＝48）に合わせています。テンポが途中で変わる曲は、そのマップに追従します。
