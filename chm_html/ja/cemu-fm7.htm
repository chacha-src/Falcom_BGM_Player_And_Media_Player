CEmu：FM-7

FM-7 と FM77AV の zip のうち、いま鳴ることが確認できたものの早見です。置き場は data\fm7 です。FM TOWNS 向けでカタログが pc98vx のものは、PC-98 の 80286 と OPNA で鳴ります。

CPU

CPU は 6809 です。FM-7 も FM77AV も同じ CPU で、音源だけが違います。

音源チップ

欄部品どんな音か
PSGAY-3-8910FM-7 本体の PSG。
OPNYM2203FM77AV の FM 音源。

同じ zip 名で FM-7 と FM77AV の両方が確認できているときは、PSG と OPN の両方に ○ が付きます。表に無いものはまだ演奏できません。
