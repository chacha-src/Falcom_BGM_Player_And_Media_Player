VSTホストで音源を鳴らす

VSTホストは、手持ちの VST プラグイン（音源）を読み込んで、MIDIキーボードからリアルタイムに鳴らすための画面です。メディアプレイヤー下段の「VST」ボタンから開きます。プレイリストの .mid を VST で鳴らす話は .mid を VST 音源で鳴らす をご覧ください。

VSTホスト（プラグインとパート割当）

音を出すまで

  1. 下段の「VST」を押してホストを開きます。左にプラグイン一覧、右に Part 1〜32 の配線があります。
  2. 一覧に出ないときは「再スキャン」、または右クリックの「プラグイン再スキャン」を実行します。一覧には、実際にパートへ載せられて鳴るもの、または音色選択が必要なものだけが出ます。同じ音源が複数フォルダにあるときは、先に見つかって実際に載せられるものだけを残します。設定の共用DLL（GS/XG）も探します。名前のあとの &lt;x86&gt; &lt;x64&gt; はビット数、&lt;音色選択&gt; はプラグイン画面で音色を選ぶ音源、[M16ch] は16チャンネルのマルチです。エフェクトなど載せられないものは出ません。HALion 7 や Groove Agent は開かずに即確認します。
  3. 使いたいプラグインを、右の Part 1〜32 のどれかへドラッグします。音色選択型は先頭のライブラリ音色を読み込まないので、ドロップも速くなります。
  4. 上の「MIDI入力 1〜3」で鍵盤を選びます。同じ機器でも 1-16ch（パート1–16）と 17-32ch（パート17–32）が並びます。1台目を 1-16ch、2台目を 17-32ch にすればチャンネルを分けられ、3台目も同じ帯域から選べます。同じ機器を複数口に当てると Super-MPU のように 32 パートへ届きます。その右の「メイン再生」で「メイン再生スルー」を選ぶと、プレイヤーで鳴っている音（mp3 など形式不問）をこのホストへ回します。MIDI入力 1–3 と同時に使えます。スルー中はプレイヤー本体のスピーカーは無音になり、音はホストの「音声出力」からだけ出ます。MIDI のときは SMF も鍵盤と合流します。
  5. 鍵盤を押すと、そのパートの音が鳴ります。&lt;音色選択&gt; と付いているものは、スロットのボタンでプラグイン画面を開き、音色を選んでから弾きます。

画面の主な操作

プリセット
配線とデバイスの組み合わせを保存・切替・名前変更・削除できます。
再スキャン
プラグイン一覧を探し直します。実際にパートへ載る音源だけが残ります。名前のあとに &lt;x86&gt; &lt;x64&gt;、&lt;音色選択&gt;、[M16ch] が付きます。HALion 7 や Groove Agent は開かずに即&lt;音色選択&gt;です。鳴る音源は音が乗った時点で確認完了です。
保存 / 名前変更 / 削除
プリセットの管理です。
MIDI入力 1〜3
鍵盤などのハードウェア。各機器は 1-16ch（パート1–16）と 17-32ch（パート17–32）で選べます。3台まで同時に開けます。
メイン再生
「メイン再生スルー」で、プレイヤーで鳴っている音をこのホストへ回します。MIDI入力 1–3 と同時に使えます。
一覧の絞り込み
プラグイン名で一覧を細かくします。&lt;x64&gt;などタグでも絞れます。
音量
このホストの出力音量です。鍵盤や VST、メイン再生スルーのミックス全体にかかり、WAV出力にも同じ倍率がかかります。
WAV出力
このホストのミックスを WAV へ書き出します。メイン再生スルー中は、プレイヤーで鳴っている音も混ざります。もう一度押すとファイルが確定します。とても長い録音でも大丈夫です。

MIDI入力の 1-16ch / 17-32ch

MIDI入力 1・2・3 の一覧には、接続機器ごとに 機器名 1-16ch と 機器名 17-32ch が並びます。1-16ch は Part 1–16、17-32ch は Part 17–32 へ入ります。2台以上の鍵盤をチャンネルで分けたいとき、同じ鍵盤を 32 パートへ重ねたいとき、どちらもこの一覧だけで足ります。名前に MPU が付く Super-MPU 系は、1-16ch を選んだだけで 17–32 へもメッセージが飛びます（F5 のケーブル指定にも従います）。配線キャンバスの右クリックからも、MIDI入力 1 / 2 / 3 のサブメニューで同じ指定ができます。

「メイン再生」はハードウェアではなく、プレイヤーで鳴っている音をホストへ回すスイッチです。MP 画面などで普通に再生している音が入り、ホストの VST と合成できます。mp3 や KPI、動画の音声など、形式は問いません。MIDI を再生しているときは、その SMF も鍵盤と合流します。WAV出力はそのミックスを録ります。スルー中はプレイヤー本体のスピーカーは無音になり、音はホストの「音声出力」からのみ出ます。MIDI入力 1–3 と同時に使えます。

スロット（パート）の操作

  • スロット上のボタン …… そのプラグインの設定画面を開きます。
  • ▼ …… チャンネルやプログラム／キットを選びます。
  • 右クリック …… 「設定画面を開く」「プラグインに渡すチャンネル」（受信したチャンネルのまま／ch1–16）、「プログラム／キット」、MIDI入力 1 / 2 / 3、メイン再生スルー、「MIDIモニタを開く」、「このスロットを解除」「プラグイン再スキャン」「プリセットを保存」。

パソコンのキーボードでも

MIDI機器が無くても、パソコンのキーボードで簡易演奏できます。下段のキーがだいたい C4 付近、上段が C5 付近です。Space ですべての音を止めます。文字入力中の欄にフォーカスがあるときは無効です。

マルチ音源のあつかい

SOUND Canvas VA や SGP2 のような、1つで複数の楽器を持つ音源は、1スロットで16チャンネルぶんを受け持ちます。チャンネルごとに違う楽器を鳴らせます。

64bitのプラグインについて

64bit のプラグインは KpiHost64 経由で読み込まれます。KPIプラグインで対応形式をふやす と同じ仕組みです。

ヒント

MIDI機器が無いときは、スマホやPCから操作する のピアノタブからも試せます。演奏中の SMF や、ホストの鍵盤入力を見るなら MIDIモニタ をどうぞ。

注意

「このプラグインには設定画面がありません」と出るものは、ウィンドウを開けないタイプです。音は鳴ります。
