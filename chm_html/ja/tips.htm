ちょっとしたコツ

ここには「知っていると得をする」小さなことを集めました。困ったときの確認先としても使えます。

音が出ない・おかしい

そもそも音が出ない
レンダリング設定 の再生デバイスを確かめます。Windows のミキサーでこのアプリがミュートされている場合は、起動時に警告が出ます。
音がプツプツ切れる
レンダリング設定 でバッファを大きくします。連続再生クロスフェード や録画を使っているときは、負荷が高くなっています。
音量を上げても足りない
本体の音量、イコライザーと環境モデル のマスター、拡張音量は別系統です。3つとも確かめてください。
音がこもる・変な効果がかかったまま
DJパッドで遊ぶ のフィルタや Kill が残っていないか、イコライザーと環境モデル の環境モデルがかかっていないかを見てください。
モノラルで聴くと音が薄い
音を整えるツール の左右のバランスを見て、広がりを調整してください。

曲が見つからない

  • ゲームBGMなら ゲームフォルダの設定 を確かめます。
  • プレイリストの欠損マークは プレイリストを使う の欠損ファイル確認でまとめて直せます。
  • 外付けドライブのドライブレターが変わっていないかを見てください。

覚えておくと便利なつながり

  • BPMを測る → 拍グリッド、連続再生クロスフェード の秒数、DJパッドで遊ぶ の ±拍
  • キー確定 → Camelot相性で次曲の候補、キー→EQ提案
  • タグを編集する → 歌詞を表示する のネット取得、スマートプレイリストと書庫ツリー の条件
  • キュー、A-B、練習テンポ → A-B／キュー素材パックで切り出し
  • 演奏プロンプトで曲を動かす → 音声書き出し（WAV / mp3 / FLAC） の「プロンプト実行を適用」でファイルへ反映

曲ごとに覚えられるもの

BPM、拍のずれ、キーは SongParams.dat に曲ごとに保存され、次に再生したときに戻ってきます。

音量やEQなどの設定は、「曲ごとに設定保存」をONにすると★の付いた曲に保存されます。チェックを外すときは、その時点の設定をその曲へ保存してから無効になります。

うっかり消してしまったとき

プレイリストの行を消してしまったら、右クリックの「削除を元に戻す」で1段だけ戻せます。何段も戻すことはできないので、気付いたらすぐ実行してください。
