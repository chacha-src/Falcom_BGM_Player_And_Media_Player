SASAMI .mpw2 — .mpy からの差分

.mpw2 のストリーム命令は .mpy コマンド と同じ番号です。違うのはファイル先頭とトラック表、入れ子ループをそのまま持てることです。VST やマクロは .mpsmv です。

ヘッダの違い

  • 先頭 EE EE EE CR LF と ASCII SASAMI MPY Ver2.2。
  • トラック表は 0x200 から 24bit アドレス＋1 バイト part。最大 64 本。
  • 0x82＝dualPort（1 でポート2 を使う cmd38 が生きる）。0x83＝1（wide）。
  • 曲名位置は .mpy と同じ 0x160。

ストリームで変わらないこと

cmd10 / cmd24 の飛び先は .mpy と同じ 16bit 絶対（0x1xxx）です。24bit なのはトラック表だけです。ここを 24bit で読むとループが壊れます。

入れ子ループ

cmd23/24 のスタックは最大 16 段。Composer は|:n の入れ子が 2 段以上なら .mpw2 にします。1 段だけなら .mpy のままでも同じ音です。

二重ポート

cmd38 でそのトラック以降をポート2 へ送ります。ヘッダ 0x82 が 0 だとポート2 は開きません。テキストの [port:ch] がこれに対応します。

Composer が .mpw2 を選ぶとき

  • MIDI でループ入れ子 ≥ 2。
  • VST / @CC / ネイティブ ｛: / @MACRO が無い。
  • 譜面で 32ch 超や dual port を使う保存。

@SVIB / @STREM / @SPAN / @SPORTA は.mpw2 でもクラシック命令へ展開します。プレイヤーは cmd46/47 を読めますが、Composer は出しません。

ヒント

SMF 変換音源（55map / 88map / XG 等）は .mpy も .mpw2 も同じkbsasami.midimode です。
