WAVへ保存する

「WAVへ保存」は、いま鳴っている音をそのままファイルへ書きながら再生する機能です。ファルコムBGM画面からの変換にも、メディアプレイヤーで聴いている音の記録にも使えます。

ファルコムBGM画面からの変換

  1. ファルコムBGM画面 で曲を選びます。
  2. WAVへ出力を選びます。
  3. ループ回数とフェードアウトを決めます。
  4. 保存先を指定して実行します。

mp3 や FLAC がほしいときは、メディアプレイヤーの 音声書き出し（WAV / mp3 / FLAC） を使ってください。

聴きながら記録する

「WAVへ保存」をONにして再生すると、聞こえている音がそのまま書き込まれます。停止するとファイルが確定します。

マイクを混ぜる（マイクミックス）

「WAVへ保存」がONのとき、再生している音にマイクの入力を混ぜて書き込めます。曲に合わせて歌ったり、コメントを入れたりできます。

  • マイクの端末は レンダリング設定 で選びます。
  • 混ぜる量は 0〜200% で調整できます。
  • ON/OFF はメディアプレイヤーのプレイリスト右クリックからも切り替えられます。
  • 声を変えて入れたいときは ボイスチェンジャー と組み合わせられます。

クロスフェードと一緒に使うとき

連続再生クロスフェード がONのときは「チェック用」モードになります。

  • 最初に流した曲名のWAVへ、そのまま追記し続けます。
  • 出力は 96 kHz / 2ch / 24bit に固定されます。聞こえている混合PCMを変換したものです。
  • 停止でファイルが確定します。

大きなファイルについて

2GBを超える場合は RF64 形式になるので、長時間でも問題ありません。

ヒント

「聴いている音をあとで編集したい」のではなく「スピーカーから出ている音をまるごと録りたい」場合は、再生している音を録音する のほうが向いています。他のソフトの音も一緒に入ります。

注意

レコードやカセットなど、外から入ってくる音を録りたいときは アナログ起こし台 を使ってください。ノイズ対策の機能が付いています。
