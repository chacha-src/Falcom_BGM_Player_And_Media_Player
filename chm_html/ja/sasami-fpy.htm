SASAMI .fpy コマンド（全部）

kbsasami が読むクラシック .fpy（YM2608 OPNA / YM2203 OPN / BEEP）の使えるコマンドを全部載せます。テキストや譜面からどう命令に化けるかはSASAMI Composer の対応表を見てください。入れ子ループや Misao PCM などは .fpy2 の差分 です。

ファイルの形

先頭 10 本のワードがチャンネルポインタ（絶対アドレス 0x1xxx。未使用は 0x10F0）。0x1C の versionWord はクラシックなら 0。0x1E が 0xFFFF なら OPNA 10ch。曲名・作者・コメントは Shift-JIS で 0x50 から 64 バイトずつ。ストリーム本体はファイルオフセット 0x100 付近から、命令は基本 3 バイトです。

  • ポインタ 0 または 0x10F0、飛び先 0xF0 はチャンネル終了。
  • FNEIRO（cmd2）のオペランドが 0xFE00|番号 のときは、ファイル末尾の 25 バイト音色ブロックへパッチされます。
  • 再生音源はプレイリストの「ささみ☆ﾐ FMモード」または kbsasami.fmmode。0=BEEP、1=OPN（FM3+SSG3）、2=OPNA（既定）。

チャンネル

内部は 0 始まり。テキストの #n は 1 始まり（#1＝ch0）です。

内部テキスト役割
0..2#1..#3FM 1–3（YM2608 バンク0）
3..5#4..#6SSG A/B/C。音量は PSG 0..15
6#7リズム（OPNA の $10。BEEP/OPN では休み）
7..9#8..#10FM 4–6（OPNA バンク1。OPN では使わない）

テンポの単位

cmd9 の T は「1 tick の長さ = 出力Hz × T / 1248000 サンプル」です。T=0 は既定値。Composer の t120 / T120 はこの T に変換されます。

バイナリ命令（全部）

特記がなければ 3 バイト [cmd][b1][b2]。ワード w1 はリトルエンディアンです。

cmd名前オペランド働き
0FNOTEb1=音程バイト、b2=待ちFM/SSG を key-on。音程は上位ニブル＝オクターブ、下位＝音名。リズム ch は待ちだけ。
1FKYUb2=待ちkey-off して休符。
2FNEIROw1=音色ビルトイン 0..31、または埋め込み 25 バイト音色の絶対アドレス。Composer の @n。
3FJUMPw1=飛び先無条件ジャンプ。0xF0 で終了。Composer の J。
4PSGVOLb1=0..15SSG 音量。#4..#6 の v。FM ではレジスタ番号をずらして書く。
5NEXTF—3 バイト読み飛ばし（互換スタブ）。
6PSGANDb1=レジスタ、b2=マスクSSG レジスタを AND。
7PSGORb1=レジスタ、b2=ビットSSG レジスタを OR。
8FMOUT / PSGOUTb1=レジスタ、b2=データYM へ直接書き込み（XCHG 後 AL=data, AH=reg 相当）。
9FTMPOw1=Tテンポ。t / T。
10FSLRb2=待ちkey-off しない待ち。Composer の @FSLR（書き出しは .fpy2 寄り）。
11FVOLb1=YM TL0=大きい、127=無音。FM の v。
12FPICHb1=A4、b2=A0F-number 直書き（リトルエンディアンではない）。
13ループ開始b1=回数スタックへ回数。|:n。クラシックプレイヤーは 1 段が想定。
14ループ終端w1=戻る位置回数を減らし、残っていれば戻る。戻る前に key-off。:|。
15PPICHb1/b2=周期SSG 周期直書き（DETUNE 加算後）。
16FLRb1=LR マスクステレオ $B4 の上位ビット。@FLR。
17F2JPw1=飛び先OPNA 10ch のときだけ FJUMP。それ以外は読み飛ばし。
18FDETUNw10x8000 が中央。@DETUNE。
19frzmvlb1=0..5、b2=音量リズム音色の音量（$18+idx 下位）。
20リズムパンb1=0..5、b2$18+idx の上位 2 ビット。
21FLFO_DPb1=AMS/PMS$B4 下位。@LFO の前半。
22LFO 許可b1レジスタ $22。@LFO の後半。
23（予約）—クラシックでは何もしないで 3 バイト進む。.fpy2 で EX に使う。
それ以外読み飛ばし3 バイト未知コマンドは 3 バイト捨てて続行。cmd が途中で 0 扱いになる終了は FNOTE 側。

Composer との対応（クラシック .fpy）

テキスト／FM譜面はコンパイル時に上の命令へ落とします。ループ入れ子が 1 段まで、かつ FPY2 専用の @ が無ければ .fpy になります。

cdefgab、+/-、#cmd0 FNOTE長さは l と数字、付点 .
r、譜面の Tick 空白cmd1 FKYU
^直前音の長さ加算タイ。key-off しないつなぎは .fpy2 のレガート

o4、＜ ＞オクターブ音程バイトの上位ニブル

再生の注意

  • FMモニタ（FM/MIDIモニタ）は kbsasami.raira=1 のとき %TEMP%\ogg_kbsasami\ へ dump します。BEEP は対象外です。
  • リズム波形はプラグインフォルダの ym2608_adpcm_rom.bin か 2608_*.WAV。
  • 未知の cmd を無視するので、壊れたストリームでも先へ進みます。飛び先が自分自身だと止まります。
ヒント

譜面 Save As はループの入れ子深さから .fpy / .fpy2 を自動で選びます。手で拡張子だけ変えても、versionWord が 0 のままならクラシック扱いです。

注意

cmd10 / 16 / 18 / 21 / 22 はクラシック FPY にもあります。ただし Composer は @FSLR @FLR @DETUNE @LFO を見つけると安全側で .fpy2 にします。
