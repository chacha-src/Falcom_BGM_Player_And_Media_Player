おまけ：昔マシンのサウンド

メディアプレイヤー画面から、昔のパソコンやアーケード基板向けの音楽データ（多くは zip のまとめ）を再生できるおまけです。ゲーム画面を動かすためのものではなく、音だけをこのプレイヤーの中で鳴らします。普通の曲と同じように、プレイリストやシークバー、イコライザーが使えます。

どんなものか

昔のマシンは、パソコン本体やゲーム基板の中に「音を出す部品」を持っていました。このおまけは、その部品の動きをまねして、当時の曲をスピーカーから出せるようにしたものです。画面の迷路やレースとは別枠で、どちらかといえば「もうひとつの再生の仕方」に近いおまけです。

  • ゲームそのものは動きません。音だけです。
  • ファルコム作品のインストールフォルダから読むBGM（ゲームフォルダの設定）とは別ルートです。
  • 対応しているまとめをプレイリストに入れると、印や曲名が付いて再生できます。
  • CPU と音源の表は、いま鳴ることが確認できた zip だけです。PC-98、PC-88、X68000、X1、MSX、FM-7、PC/AT、アーケード。

用意するもの

  1. 実行ファイル（oggYSEDbgm など）と同じ場所に arcdata.zip があること。これは「どのまとめが、どのマシン向けか」を調べるための一覧です。無いと、zip を落としても曲が特定できません。
  2. 同じく実行ファイルの近くに data フォルダがあり、その中にマシンごとの置き場があること（例：data\pc98、data\x68k、data\roms）。
  3. 聴きたい曲が入った zip を、その置き場へ入れること。すでに入っているものをそのままドラッグしてもかまいません。

フォルダ名はだいたい次のような意味です。全部そろっていなくても、手元にある分だけで聴けます。

フォルダの例どんなマシンの音か
pc98 / pc9821PC-9800。FM TOWNS でカタログが pc98vx の曲もここ
pc88 / pc88vaPC-8800。VA は V30
x68kX68000。68000 と OPM
fm7FM-7（PSG）と FM77AV（OPN）
msx / x1 / pcMSX、X1、DOS パソコン（PC/AT）
romsアーケード基板の音
注意

アーケードの roms は形式が混ざっています。一覧に載っていても、まだ音が出せないものもあります。鳴らないときは、そのタイトルがまだこのおまけの対象外だと捉えてください。

聴き方

  1. メディアプレイヤー画面を開きます。
  2. エクスプローラから zip をプレイリストへドラッグ＆ドロップするか、すでに一覧にある行をダブルクリックします。
  3. 曲が始まれば成功です。ひとつの zip に複数曲があるときは、曲の番号や名前が付いて並びます。

再生中は、ほかの音楽と同じ道具が使えます。

  • シークバーの読み方 で位置を動かす
  • イコライザーと環境モデル で音色の好みを変える
  • テンポとピッチを変える
  • 音声書き出し（WAV / mp3 / FLAC） でファイルに残す
  • 波形・周波数アナライザー や MIDIモニタ で様子を見る（鳴らし方によってはMIDIモニタが動きます）

鳴らし方を選ぶ（内蔵の音／MIDI）

タイトルによっては、次のような鳴らし方が選べます。プレイリストの行を右クリックすると、音の種類の項目が出ます。

内蔵の音チップで鳴らす
当時のパソコンや基板に近い、電子音そのものの鳴り方です。印に [OPNA] や [OPN]、[OPM] などが付くことがあります。名前は部品の愛称のようなもので、覚えなくても大丈夫です。「ゲームっぽい電子音」が欲しいときはこちらです。
MIDI で鳴らす
曲の指示を MIDI として出し、.mid を VST 音源で鳴らす や KPI の音源で聴くルートです。印は [MIDI] になります。ソフト音源の音色で聴きたいときや、譜面・モニタと組み合わせたいときに向きます。

どちらが使えるかはタイトルごとに違います。選べないときは、そのタイトルが持っている鳴らし方がひとつだけ、という意味です。切り替えると、いま聴いている曲が同じまとめなら、自動で聞き直します。

ヒント

迷ったら、まず既定のまま聴いてみてください。電子音が好みなら内蔵、柔らかくしたい・音源を差し替えたいなら MIDI、という選び方で十分なことが多いです。

ファルコムBGMとのちがい

項目ファルコムBGM画面まわりこのおまけ
主な材料ゲームのインストール先のファイルdata 以下の zip まとめ
目的作品の曲をループ付きで聴く昔マシンの音をそのまま味わう
画面タイトル一覧の専用画面も使えるメディアプレイヤーのプレイリストが中心
設定ゲームフォルダの設定arcdata.zip と data フォルダ

うまくいかないとき

zip を落としても鳴らない・エラーになる
実行ファイルの隣に arcdata.zip があるか、まとめの名前が一覧と合っているかを確認してください。別名の zip や、中身だけ差し替えたものは特定できないことがあります。
一瞬だけ鳴って止まる／無音
鳴らし方（内蔵／MIDI）を切り替えてみます。MIDI のときは レンダリング設定 の音源の好みや、VST／KPI の準備も見てください。
アーケードの曲がまったく出ない
まだこのおまけが対応していない基板の可能性があります。パソコン系（PC-98 や X68000 など）から試すと分かりやすいです。
終了や曲切り替えで不安定になる
再生を止めてから窓を閉じると安全です。最新版へ更新すると、解放まわりの不具合が直っていることがあります。更新のチェック もご覧ください。
注意

このおまけは「全部の昔ソフトが鳴る」ことを約束するものではありません。一覧にあっても音が出ないもの、途中までしか進まないものはあります。遊べる範囲は版によって広がっていきます。

ヒント

普通の音楽ファイルと同じく、プレイリストに並べてギャップレスやクロスフェードの雰囲気を試せます。ただし曲の終わり方はタイトルごとに違うので、ループ感は 再生詳細 や曲そのものの作りに左右されます。

クレジット

このおまけの音まわりでは、次の成果を使わせていただいています。ここに挙げきれないものもあります。作者の皆さまに感謝します。

  • Neko Project II / np2kai（NP2 developer team）— PC-98 系のCPUまわり
  • Musashi（Karl Stenerud）— 68000 系のCPUまわり
  • fmgen（cisc）— FM音源まわり
  • ymfm（Aaron Giles）— YM 系の音チップまわり
  • MAME および各作者の成果物（音チップ・CPUなど。多くは BSD 系）
  • 曲の一覧データは hoot 系のカタログ形式を参照しています
