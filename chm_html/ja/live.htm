ライブ配信する

画面を録画する の「Live」チェックを入れると、MP4 を作らずに配信先へ映像と音を送ります。YouTube Live、ニコニコ、そして自分で URL を指定するカスタム RTMP に対応しています。

先に用意するもの

注意

ライブ配信には、実行ファイルと同じ場所に ffmpeg.exe が必要です。無いときは、配信画面から公式ビルドを取得してそこに置けます。これがないと配信は始まりません。

YouTube Live へ送る

  1. Google の OAuth Client ID と Secret を入力します。
  2. 認証を実行して、アカウントとつなぎます。
  3. 配信枠を作ります。タイトルと公開範囲（公開・限定公開・非公開）を決めます。
  4. 配信開始を押します。

はじめて試すときは、公開範囲を非公開にしておくと安心です。映り具合や音量を確かめてから公開に切り替えられます。

ニコニコ / カスタム RTMP へ送る

  1. 配信サイトの配信ページを開いて、RTMP の URL とストリームキーを確認します。
  2. その2つをこの画面に入力します。
  3. 配信開始を押します。

音の品質

AAC のプロファイルを選べます。

  • 128 kbps …… ふつうの配信に。
  • 192 kbps …… 音楽をきれいに聴かせたいときに。
  • 低遅延 96 kbps …… 遅れを小さくしたいときに。

配信画面をきれいに作る

  • 画面を録画する のウィンドウ合成で、ゲームの画面とメディアプレイヤーを並べられます。
  • スマホやPCから操作する の /overlay は、透過の曲名表示を作るための簡易HTMLです。OBSのブラウザソースに入れられます。
  • いま鳴っている曲名は nowplaying.txt としても書き出せます。附属ツールいろいろ をご覧ください。
  • 曲の切り替えを自然にしたいときは 連続再生クロスフェード が効きます。
ヒント

配信中は手が離せません。スマホから曲を送ったり音量を変えたりできる スマホやPCから操作する を開いておくと便利です。リスナーに次の曲を選ばせたいときは、共同キューの機能も使えます。

注意

Live をONにしている間は MP4 ファイルは作られません。あとで見返したい場合は、別に録画するか、配信サイト側のアーカイブ機能を使ってください。

あわせて読みたい
  • 画面を録画する
  • スマホやPCから操作する
  • 再生している音を録音する
  • 連続再生クロスフェード
  • 附属ツールいろいろ
