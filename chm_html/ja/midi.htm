MIDIキーボードで操作する

MIDIキーボードやコントローラをつなぐと、ノート（鍵盤）や CC（つまみ・フェーダー）でこのソフトを操作できます。マウスから手を離して、楽器のように扱えるようになります。

できること

  • 鍵盤を押して、再生・停止・次の曲などを実行する。
  • つまみやフェーダーで音量を動かす。
  • テンポや イコライザーと環境モデル の帯を、つまみで連続して動かす。
  • DJパッドで遊ぶ の操作を手元の機器に持ってくる。

MIDI学習で割り当てる

  1. 割り当てたい機能を選びます（たとえばテンポ）。
  2. MIDI学習を待ち受け状態にします。
  3. 手元のつまみを動かします。そのつまみのCCが覚えられます。
  4. 以後は、そのつまみでテンポが動きます。

覚えさせた割り当ては保存されるので、次に起動したときも同じ機器でそのまま操作できます。

音源を鳴らしたいとき

MIDIで音を出したい（このソフトを音源として使いたい）場合は、VSTホストで音源を鳴らす を使います。MIDI入力は最大3台まで受けられて、パートへリアルタイムに送られます。プレイリストの .mid を VST で鳴らすときは .mid を VST 音源で鳴らす、演奏状態の一覧は MIDIモニタ です。

ピアノロールとの関係

ピアノロールで音を見る は、鳴っている音を拾って MIDI や MusicXML として書き出せます。「弾いたものを記録する」のではなく「鳴っている曲を譜面にする」働きです。

ヒント

MIDI機器を持っていなくても、スマホやPCから操作する のピアノタブを使えばスマホの画面を鍵盤の代わりにできます。

注意

機器をつないだあとに認識されないときは、いったんソフトを再起動してみてください。ほかのソフトがその機器をつかんでいる場合も、認識できないことがあります。
