CDプレイヤー

メディアプレイヤー下段の「CD」から開きます。ドライブの目次を読み、曲を聴き、MusicBrainz や GnuDB などで曲名を引き、WAV / MP3 / FLACへ取り込み、オーディオCDやデータCDを書くところまで、この窓で揃います。

開きかた

メディアプレイヤー下段、VSTと迷路のあいだにある常時表示の「CD」を押します。コマンドパレットから「CDプレイヤー」でも開けます。位置と大きさは次に開いたときも覚えています。

再生

  1. 上のドライブ一覧から光学ドライブを選び、「読込」で目次を読みます。入っていれば CD-TEXT もここで載せます。
  2. 曲リストをダブルクリックするか「再生」で、その曲を鳴らします。メインの再生とは別なので、プレイリストを止める必要はありません。本体のイコライザー（サラウンド含む）は常に掛かります。きれいめ再生がオンなら、それに合わせて整えます。テンポやピッチを動かしているときは、そちらも掛かります。本体の再生クロスフェードがオンなら、曲の境で次の曲へつなぎます。アナライザーとピアノロールにも、再生中の音を流します。
  3. シークは範囲スライダーです。横の A / B / A-B× で区間ループします。［ でA、］ でB、もう一度で解除。つまみでも動かせます。音量、リピート、シャッフルも画面下です。ここの音量はCDの再生にだけ掛かり、Windowsのアプリ音量や本体の主音量／DS音量は動かしません。
  4. イジェクトでトレイを開けます。ディスクの入れ替えは自動でも拾います。

曲名とジャケット

「検索」はディスクの情報から MusicBrainz と GnuDB を引き、さらに iTunes / Deezer なども足します。当たった候補はリストから選びます。手元で知りたい名前があるときは検索欄に入れて「Go」です。ジャケットは、曲名データが揃っている候補だけネットから取ります。ネットに繋がっていないと、オンライン側は取れません。

候補を一度適用すると、そのディスク向けに TEMP フォルダへ覚えます。同じディスクを入れ直したとき、そのファイルが残っていればネットへ行かず、覚えた曲名とジャケットを使います。ファイルが無いときだけ、また取りに行き、候補一覧を出します。名前の「Go」はキャッシュを使わず、毎回取りに行きます。別の候補を選ぶと、キャッシュは上書きされます。TEMP を空にすれば、次はまた一覧から選べます。

名前の編集

ジャケット横のアルバム名とアーティスト名は、そのまま入力できます。曲リストの曲名とアーティストは、選んだセルをもう一度クリックするか F2 で直に直せます。コピーした文字列は、選んでいる複数行へ一度に貼れます。タブ区切りなら曲名とアーティストを同時に渡せます。リストには曲コードの列もあります（ディスクが持っているとき）。取り込みのファイル名にも、ここで直した名前が使われます。

取り込み

形式
WAV（無圧縮）、MP3、FLAC。品質は MP3 なら kbps、FLAC なら圧縮レベルです。
選択を取り込み
リストで選んだ曲だけを、1曲1ファイルで保存します。
全曲を取り込み
すべての曲を、1曲1ファイルで保存します。
1本にまとめる
ディスクのはじめから終わりまでを1つのファイルにします。WAV書き出しのクロスフェードがオンなら、曲の境で本編の複数選択書き出しと同じつなぎ方をします。
プレイリストへ追加
できたファイルを、いまのプレイリストの末尾に足します。

読み取りは念のため二度見て、食い違うとやり直します。保存先フォルダは「...」で選べます。取り込みには、いまの本体設定（イコライザー、サラウンド、アップスケール、テンポ／ピッチ）を焼き込みます。WAV書き出しのクロスフェードがオンで2曲以上あるときは、1本にクロスフェードでつなぎます。アナライザーとピアノロールにも、取り込み中の音を流します。MP3 は2チャンネル16ビットまでなので、5.1 などのチャンネル展開は WAV / FLAC 向けです。

書き込みと消去

  • オーディオCD …… 選んだ WAV / MP3 / FLAC を、1曲ずつ音楽CDとして焼きます。
  • データCD …… ファイルをデータトラックとして焼きます。
  • RW消去 …… 書き換えディスクを消します。中身は戻りません。

右クリック

ドライブ、再生、取り込み（形式ごと）、書き込み、検索、ヘルプがサブメニューに分かれています。まとめられる操作は一段深いサブメニューにしています。「メインに追随」を付けると、本体ウィンドウの移動にこの窓もついていきます。

操作ガイドの図

窓の「？」では Soft3D の波形デモと Soft2D のディスク絵で、再生と取り込みの流れを示します。アクリルキャプションの高さは本文レイアウトに織り込んであるので、かぶさって隠れたりはしません。

ヒント

取り込み中はCD側の再生を止めます。メインプレイヤーの再生はそのままです。

注意

ドライブが無い、ディスクが音楽CDではない、読み取りが失敗する、といったときはステータス行に理由が出ます。
