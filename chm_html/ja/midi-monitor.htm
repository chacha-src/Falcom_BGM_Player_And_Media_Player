MIDIモニタ

MIDIモニタは、再生中の SMF（.mid / .midi / .kar / .rmi）を 32 パート（A01–A16 / B01–B16）で見守る画面です。オーディオから音程を推定するのではなく、ファイルに書かれた MIDI イベントそのものを表示します。

開く

メディアプレイヤーのバナーを右クリックして「ウィンドウ」→「MIDIモニタ」、プレイリストの右クリック、イコライザー／アナライザー／ピアノロールの「開く」、コマンドパレットから開けます。

見られるもの

  • ヘッダ …… BPM、テンポ%、調、タイムベース、拍子、Transpose、ファイル名。
  • 各パート …… PC / バンク / マップ、音色名、レベル、Vol / Pan / Exp / Rev / Crs / Var、ビブラート、フィルタ、エンベロープ、EQ、NRPN、ミニ鍵盤。
  • 音色名 …… 内蔵の SASAMI GS / XG 音色表から引きます。XG System On があれば XG、なければ GS として名前を付けます。右クリックの「音色マップ」で強制もできます。

表示

  • 通常の2D …… 表形式です。
  • 簡易3D …… 32 パートのレベルを箱として CPU 描画します。ドラッグで視点、ホイールで寄り引き。

GS / XG の音源

演奏に使う VST は レンダリング設定 の GS VST と XG VST です。曲が始まる前に SMF を少し読んで、XG リセット（XG System On）があれば XG 側、なければ GS 側を使います。片方だけ書いてあればそちらで両方をまかない、両方空なら Windows MIDI マッパーへ落ちます。
