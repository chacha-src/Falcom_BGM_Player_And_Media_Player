MIDIモニタ

MIDIモニタは、再生中の SMF（.mid / .midi / .kar / .rmi）を 32パート（A01–A16 / B01–B16）で見守る画面です。オーディオから音程を推定するのではなく、ファイルに書かれた MIDI イベントそのものを表示します。ピアノロールが「どの音が鳴ったか」を時間軸で見せるのに対し、こちらは「各チャンネルの音色・音量・効果」を一覧します。

MIDIモニタ

開く

  • メディアプレイヤーのバナーを右クリック → 「ウィンドウ」→ 「MIDIモニタ…」
  • プレイリストの右クリック → 「ウィンドウ」→ 「MIDIモニタを開く」
  • ピアノロールで音を見る・アナライザー・イコライザーの右クリック → 「開く」→ 「MIDIモニタを開く」
  • コマンドパレットから「MIDIモニタ」
ヒント

窓の位置と大きさは覚えられます。次に開いたときも、前回の場所に戻ります。

ヘッダに出るもの

  • BPM、テンポ%、調、タイムベース、拍子、Transpose、ファイル名
  • 全体の音量%、ノート数
  • リバーブ／コーラス／バリエーション
  • SYS（GM / GS / XG）、INSERTION 1 / 2

32行のチャンネル表

各行が1パートです。A01–A16 がポートA、B01–B16 がポートBです。

PC# / BNK / Map / Instrument
プログラム番号・バンク・GS/XGマップ・音色名です。音色名は内蔵の SASAMI GS / XG 表から引きます。
Lev / Vol / Pan / Exp
出力レベルと、音量・パン・エクスプレッションです。
Rev / Crs / Var
リバーブ・コーラス・バリエーションの送り量です。
Vibrato / Filter / Envelope / EQ / NRPN
ビブラートやフィルタ、エンベロープ、EQ、NRPN の状態です。
Keyboard（右端のミニ鍵盤）
いま押されている鍵盤が点灯します。クリックすると、そのパートの音が再生経路から出ます。

ミニ鍵盤とスライダーで鳴らす

ミニ鍵盤のクリック、音量・パンなどのドラッグは、表示だけでなく実際の音にも乗っかります。.mid を VST 音源で鳴らす のときは、曲と同じ VST（64bit 音源も含む）へ入ります。鍵盤クリックで曲を巻き戻したり、他パートの音色をリセットしたりはしません。両方の VST が空で MIDI マッパーに落ちているときも、同じ端末へ短文が行き、曲のテンポ（イベントの時間位置）と SysEx もその端末へ流れます。KPIプラグインで対応形式をふやす で MIDI を鳴らしているときは、プラグイン側に MIDI 入力が無いので、レンダリング設定の「MIDI出力」端末（未指定なら MIDI マッパー）から鍵盤と CC が出ます。

表示モード（2D / 簡易3D）

  • 通常（2D） …… 表形式。いちばん見やすい標準です。
  • 簡易3D …… 32パートのレベルを箱として描きます。OpenGL や Direct3D は使わず、CPUだけであしらいます。ドラッグで回転、ホイールでズーム、0 で視点リセット。重いと感じたら、右クリックから 2D に戻してください。

右クリックメニュー

表示モード
通常（2D）と簡易3Dを切り替えます。
フリーズ
表示の更新を止めます。確認したい瞬間を止めたいときに。
常に手前に表示
ほかの窓の上に重ねて置けます。
状態をコピー
いまの表の内容をテキストとしてコピーします。
MIDIを再読込
いまの曲の MIDI を読み直します。
音色マップ
自動（SysEx）／GS／XG。音色名の引きかたを決めます。
開く
イコライザー／ピアノロール／アナライザー／操作ガイドへ飛びます。

聞こえる音とのタイミング

.mid を VST 音源で鳴らす で再生しているときは、プラグインの遅れに合わせて、モニタの進行も実際に聞こえる位置に近づくよう少し遅れて進むことがあります。「画面と音がずれている」と感じる場合は、この調整のせいです。

ほかの機能との関係

  • ピアノロールで音を見る …… ノートの時間軸。モニタはチャンネル状態。
  • .mid を VST 音源で鳴らす …… GS/XG VST で鳴らしている曲を見守れます。
  • VSTホストで音源を鳴らす …… 鍵盤からリアルタイムに鳴らす画面（モニタとは別）。
  • MIDIキーボードで操作する …… 再生操作やEQを鍵盤に割り当てる機能です。
ヒント

「？」ボタンを押すと、この画面専用の図解（操作ガイド）が出ます。各画面の「？」操作ガイド もご覧ください。

注意

音声ファイル（mp3 など）の再生では MIDI イベントが無いのでモニタは動きません。SMF を再生しているとき専用の画面です。
