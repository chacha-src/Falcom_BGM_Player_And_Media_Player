MIDIモニタ

MIDIモニタは、再生中の SMF（.mid / .midi / .kar / .rmi）を 32パート（A01–A16 / B01–B16）で見守る画面です。ピアノロールのように音を推測するのではなく、MIDIファイルに書いてある通りを表示します。ピアノロールが「どの音が鳴ったか」なら、こちらは「各パートの音色・音量・効果」の一覧です。

MIDIモニタ

開く

  • メディアプレイヤー下段、VST と CD のあいだの常時表示「MIDI」（開いているあいだ凹みます）
  • メディアプレイヤーのバナーを右クリック → 「ウィンドウ」→ 「MIDIモニタ…」
  • プレイリストの右クリック → 「ウィンドウ」→ 「MIDIモニタを開く」
  • ピアノロールで音を見る・アナライザー・イコライザーの右クリック → 「開く」→ 「MIDIモニタを開く」
  • VSTホスト の配線キャンバスを右クリック → 「MIDIモニタを開く」
  • コマンドパレットから「MIDIモニタ」
ヒント

窓の位置と大きさは覚えられます。次に開いたときも、前回の場所に戻ります。

ヘッダに出るもの

  • BPM、テンポ%、調、タイムベース、拍子、Transpose、ファイル名（シーケンス名があれば横に出す。「???」だけの名前は出さない）
  • 全体の音量%（DS）、ノート数、DRUM
  • DRUM の右：いまの小節/総小節（001/051）、いまの拍/1小節の拍数（1/4→2/4→3/4→4/4）、小節内 tick / 1小節の tick（0000/1920）。再生位置に合わせて動きます。拍子が途中で変われば分母も変わります。
  • リバーブ／コーラス／バリエーション
  • SYS（GM / GS / XG）、INSERTION 1 / 2（ON/OFF ではなく、Thru・Distortion・Over Drive など XG インサーション／Variation（インサーション接続時）／GS EFX の正式名称）

32行のチャンネル表

各行が1パートです。上の16行が前半、下の16行が後半です。ドラムは曲の指定に従います（10番だけがドラム、とは限りません）。VST 再生では GS リセットのあと A10/B10 をリズムへ切り替えます。XG では ch10 にドラムバンクを送ります。.mid を VST 音源で鳴らす もご覧ください。

追いつき中は、同じアドレスの SysEx と種類ごとの CC は最後の値だけ適用します。32ch を何度も回す初期化でも途中経過は捨て、再生位置の最新へ一気に合わせます。

描画は 16ms ごとに「絵が変わった行」だけです。バーは1ピクセル動いたときだけ、ミニ鍵盤は押している音が変わったときだけ塗り直すので、32パートが同時に鳴っても全面を描き直しません。

PC# / BNK / Map / Instrument
プログラム番号・バンク・GS/XGマップ・音色名です。音色名は内蔵の SASAMI GS / XG 表から引きます。
Lev / Vol / Pan / Exp
出力レベルと、音量・パン・エクスプレッションです。バーが狭いので、Vibrato の Rat/Dpt と同じく2行にして、1つおきに上下へ書きます。
Rev / Crs / Var
リバーブ・コーラス・バリエーションの送り量です。
Vibrato / Filter / Envelope / EQ / NRPN
ビブラートやフィルタ、エンベロープ、EQ、NRPN の状態です。見出しは下の数値と同じ横位置です。
Keyboard（右端のミニ鍵盤）
いま押されている鍵盤が点灯します。クリックすると、そのパートの音が再生経路から出ます。

色の見方

  • 使っているパートのインスト名・パラメータ・ミニ鍵盤は、白と少し暗い白が1行おきです。
  • ノート・CC・SysEx がまだ来ていないチャンネルは灰色です。ミニ鍵盤をクリックして鳴らすと、交互の白／オフホワイトに戻ります（ドラムなら暖色）。
  • ドラムパートは行全体（CH#・音色名・パラメータ・鍵盤）を暖色にします。
  • PC# / BNK / Map は発音中も行の交互色のままです。発音はミニ鍵盤と Lev バーで見ます。
  • 音色が変わるとインスト欄が琥珀に点きます。Lev/Vol などのバーはフェードしません。

ミニ鍵盤とスライダーで鳴らす

ミニ鍵盤のクリックや音量のドラッグは、表示だけでなく実際の音にも乗っかります。.mid を VST 音源で鳴らす のときは、曲と同じ音源へ入ります。鍵盤をクリックしても、曲は巻き戻りません。Windows の MIDI で鳴らしているときも、同じ出口へ届きます。KPIプラグインで対応形式をふやす で MIDI を鳴らしているときは、レンダリング設定の「MIDI出力」から鍵盤の音が出ます。

表示モード（2D / 簡易3D）

  • 通常（2D） …… 表形式。パートの間に薄い横線。いちばん見やすい標準です。
  • 簡易3D …… 32パートのレベルを箱として描きます。OpenGL や Direct3D は使わず、CPUだけであしらいます。ドラッグで回転、ホイールでズーム、0 で視点リセット。重いと感じたら、右クリックから 2D に戻してください。

右クリックメニュー

聞こえる音とのタイミング

.mid を VST 音源で鳴らす で再生しているときは、ノート表示はプラグインの遅れと出力の進みに合わせて少し遅れることがあります。ただし先頭のノートが乗るまでは SysEx/CC は遅らせず、頭のダンプを表示遅延に引きずりません。一度ノートが乗ったら、SysEx/CC も聞こえる位置に合わせます。

ほかの機能との関係

  • ピアノロールで音を見る …… ノートの時間軸。モニタはチャンネル状態。
  • .mid を VST 音源で鳴らす …… GS/XG VST で鳴らしている曲を見守れます。
  • VSTホストで音源を鳴らす …… 鍵盤からリアルタイムに鳴らす画面。ホストを開くと、その MIDI 入力とミニ鍵盤がこのモニタとつながります。
  • MIDIキーボードで操作する …… 再生操作やEQを鍵盤に割り当てる機能です。
ヒント

「？」ボタンを押すと、この画面専用の図解（操作ガイド）が出ます。各画面の「？」操作ガイド もご覧ください。

注意

音声ファイル（mp3 など）の再生では MIDI イベントが無いのでモニタは動きません。SMF 再生中、または VSTホスト で鍵盤／MIDI入力しているときに使います。
