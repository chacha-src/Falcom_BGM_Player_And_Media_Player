プレイリストを使う

プレイリストは曲を並べておく場所ですが、それ以上に「この曲に何かする」ための入口でもあります。行を右クリックすると、タグ編集から書き出しまで、できることが一覧で出ます。

プレイリストはメイン画面下部に並びます

曲を入れる

  • エクスプローラからファイルやフォルダをドラッグ＆ドロップします。フォルダごと入れられます。
  • 他のソフトのプレイリストを取り込む場合は 他のソフトのプレイリストを取り込む へ。
  • 条件を書いておいて自動でたまるようにしたいなら スマートプレイリストと書庫ツリー へ。

並べる・動かす

  • 列の見出しをクリックすると、その項目で並べ替えます。
  • 選んだ曲を別のプレイリストへ移動またはコピーできます。
  • 一時プレイリストを作れば、いま聴きたい曲だけをさっと集められます。元のリストはそのまま残ります。
  • Up Next キュー に入れた曲は、いまの再生順を無視して次に流れます。順番の入れ替えもできます。

行に出るしるし

♪
いま再生している曲です。点滅します。
♡
選んでいる曲です。
★
曲ごとの設定（音量・イコライザーなど）を覚えている曲です。
欠損マーク
ファイルが見つからない曲です。
印列のチップ（橙 SAV / 青 LRC / 緑 MONO·LR·2.1…）
名前の近くや「印」列に出ます。橙は曲ごと保存、青は歌詞（.lrc）あり、緑はチャンネル数です。WAV や FLAC は一覧時にヘッダから読み、VST MIDI や m4a などは再生（または 連続再生クロスフェード の先読み）で確定したあとに付きます。

右クリックからできること

項目内容
ファイル情報ファイル情報を見る・直す
タグ編集タグを編集する
音声書き出し音声書き出し（WAV / mp3 / FLAC）
再生詳細再生詳細
アナライザー / ピアノロール波形・周波数アナライザー / ピアノロールで音を見る

整える

欠損ファイル確認
見つからない曲を一覧にして、パスを直したりまとめて適用したりできます。行の中で直接編集もできます。直したあとは再スキャンでマークを消せます。
重複ダイアログ
同じ曲が二重に入っていないかを調べて、整理できます。
フォルダ同期リスト
指定したフォルダの中身とプレイリストを合わせておけます。フォルダに曲を足したら、リストにも入るようにできます。
★レーティング
曲に星を付けて、あとで スマートプレイリストと書庫ツリー の条件に使えます。
ヒント

曲ごとに音量やイコライザーを変えたいときは「曲ごとに設定保存」を使います。★が付いた曲は、次に再生したときに保存した設定で鳴ります。

注意

動画ファイルや再生できない行は、連続再生のときに自動で飛ばして次の音声曲へ進みます。動画をきちんと見たいときは 動画を再生する をご覧ください。
