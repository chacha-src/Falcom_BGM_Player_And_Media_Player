コマンドロールで並べる

コマンドロールは、演奏プロンプトで曲を動かす の命令を目で見て並べるための画面です。横が時間、縦がレーンになっていて、「この時間にこれを起こす」をブロックとして置いていけます。

開く

メディアプレイヤーの「ロール」ボタン（コマンドロール側）から開きます。

並べかた

  1. 命令を置きたい時間のところをクリックします。
  2. 「コマンド配置」で何を起こすかを決めます。
  3. 置いたブロックは、あとから動かして時間をずらせます。
  4. レーンを分けると、同じ時間に複数のことを起こせます。

見やすくする

表示倍率
横に伸ばすと細かい時間を、縮めると曲全体を見渡せます。倍率は保存されるので、次に開いたときも同じ見え方です。
メイン画面に追随
ロックをONにすると、メイン画面を動かしたときに一緒についてきます。別々に置きたいときはロックを外してください。
複数レーン
テンポの動きとエフェクトの動きを別のレーンに分けると、全体の流れが読みやすくなります。

プロンプトとの行き来

ロールで並べた内容とプロンプトのテキストは、同じものを別の見た目で扱っています。「ざっくりロールで置いて、細かい数字はテキストで直す」という進め方ができます。

結果をファイルにする

並べた動きをそのままファイルにしたいときは、音声書き出し（WAV / mp3 / FLAC） で「プロンプト実行を適用」を使います。

ヒント

この画面にも「？」の操作ガイドがあります。「プロンプトロール操作ガイド」として、ブロックの置き方が図で出ます。各画面の「？」操作ガイド をご覧ください。

注意

コマンドロールは時系列の自動化を並べる場所です。その場の手動操作は DJパッドで遊ぶ や MIDIキーボードで操作する が向いています。

あわせて読みたい

  • DJパッドで遊ぶ
  • MIDIキーボードで操作する
  • 音声書き出し（WAV / mp3 / FLAC）
